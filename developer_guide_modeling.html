18 · 新增问题的最小可运行扩展

18.1 不改核心库的优先方式

下面定义一维 Poisson 制造解。它展示真实 PDEProblem 契约，而不要求修改训练器。源项按已知函数构造；exact_solution 只在评价被调用。

import math
import torch
import openpinn as op

def make_problem():
    domain = op.Interval(0.0, 1.0)

    def residual(x, u):
        source = math.pi**2 * torch.sin(math.pi * x[:, :1])
        return -op.hessian(u, x, i=0, j=0) - source

    def exact(x):
        return torch.sin(math.pi * x[:, :1])

    return op.PDEProblem(
        domain,
        residual,
        [op.DirichletBC(0.0, name="boundary")],
        exact_solution=exact,
        name="manual_poisson",
        metadata={"kind": "custom_static", "residual_names": ["pde"]},
    )

problem = make_problem()
print(op.check_method_compatibility(problem).to_text())
result = op.solve(
    problem,
    method="baseline",
    steps=5,
    model={"hidden_layers": [8, 8]},
    sampling={"interior": 16, "boundary": 8},
    output_root="runs/manual_custom",
)
print(result.metrics)

18.2 新增内置简称

  1. 在 benchmarks.py 或独立问题模块实现工厂，并有残差/条件单测。
  2. 在默认 ComponentRegistry 注册 problem 工厂；检查 _validate_config 对参数白名单的行为。
  3. 在 api._problem_defaults 加入简称及合理默认 model/sampling/loss/evaluation。
  4. 在 method_registry.problem_family 的判定中正确声明问题族，不能为放行方法而冒用不符合的族。
  5. 需要网页选择时更新 Sphinx payload 的 problems 目录；检查参考列维度、工厂选择、生成代码及显示分支。
  6. 新增 configs/experiments、示例、smoke 和 output-contract 测试。

新问题必须提供单位说明、输入/输出约定、参考解是否存在、适用条件与失败边界。只有名称出现在下拉框中不算接入完成。

06 · PDEProblem、坐标、输出与残差契约

对象形状 / 语义消费者
coordinates(N, domain.dim)，时空域最后一维是 t模型、残差、条件、几何判断
prediction(N, output_dim)残差、条件误差、评价
残差函数返回单个 (N,1) Tensor 或非空 name→(N,1) 映射PDEProblem.evaluate_residual
exact_solution(N,output_dim)，仅评价Experiment.run / problem.exact
field_names非空唯一字符串序列，长度等于 output_dim逐场 metrics/predictions 命名
metadata.residual_names自定义具名 PDE 项列表短入口默认损失权重键

PDEProblem.__init__ 接受 residual/pde、conditions/bcs 的别名，但不允许一对别名同时提供；不要求继承新问题类，函数式组装即可。evaluate_residual 检查坐标宽度、批大小、输出维度、残差形状和重复名称。单 Tensor 统一命名 pde；多个方程请返回字典，不能直接返回 (N,K) 当一个残差。

exact 拒绝没有参考函数或错误形状；reference 不是训练标签。多输出 Dirichlet 可使用匹配的向量目标；当前 NeumannBC/RobinBC 明确只支持标量输出，不能照搬到多场模型。

默认损失键的联动

_default_problem_loss_weights 读取 residual_names（缺省 pde）并追加 condition.name，遇到重复名字加后缀；StrongFormulation 也按同样方式生成条件项名称。新增多残差问题时若漏写 residual_names，自适应权重可能找不到正确项。建议所有条件取清晰且唯一的名字，避免依赖后缀。

自动微分注意点

grad、hessian 在 autodiff.py。残差中使用 torch 运算并保留计算图；不要把 prediction 转 NumPy、调用 .item() 再拼回 Tensor，否则会切断反向传播。残差中的索引应保留列维度，如 u[:,0:1]；二阶导数需要足够可微的网络/激活。

07 · 几何、采样点与法向的联系

geometry.py 提供 Interval、Disk、Ellipse、RoundedRectangle、Polygon、ClosedSpline、RectangleWithCircularHoles、SpaceTimeDomain。共同使用 dim、bounds、contains、内部/边界采样接口；支持导数边界的二维几何还提供 boundary_normal。没有单独公开的 Rectangle 类，页面矩形路径使用可用域对象生成。

实现关键逻辑维护风险
Interval一维范围、端点采样、区间判断上下限合法性；端点 BC 的左右符号
Disk参数圆域，直接圆周采样与法向半径必须正且有限
Ellipse中心+局部半轴+旋转；局部/全局坐标变换旋转单位、法向变换、等弧长近似采样
RoundedRectangle直段与圆弧共同构成边界r=0 与最大半径退化情况
Polygon外环+孔洞、方向标准化、相交检查、内部判断、边界/边长采样内外环朝向、短边漏采样、自交及孔洞碰触
ClosedSpline闭合 cardinal 样条→三次 Bézier 段；解析导数给法向，密折线用于内部判断张力不是曲率；验证采样密度不能证明任意控制点绝无局部自交
RectangleWithCircularHoles矩形减去给定圆孔的专用几何孔位置/重叠检查与朝孔内的外法向
SpaceTimeDomain空间域×时间 Interval，拼接时间；独立生成 initial 点空间维数+1；法向导数不应引入时间分量

ClosedSpline 默认 tension=0.2、resolution=32，resolution 允许 8–256，至少四个控制点。边界是在三次曲线上采样，不等同于直接用控制多边形边界；但域内判断与弧长表仍存在数值近似，应在精细几何问题测试收敛。

Polygon 的前后端双校验

浏览器通过 normalizeRing / validatePolygon 阻止明显错误；Python 通过 _normalise_ring、_segments_intersect、_rings_intersect 等重新校验。必须保留 Python 校验，生成脚本可被手工修改，不应信任“前端已检查”。边界法向使用计算域外侧，孔洞方向与外环相反。

导入圆孔的解析与近似分流

importedGeometryInfo 检查外环是否为四顶点轴对齐矩形、各孔是否都有 circle metadata；符合时，generatedProblemLines 使用 RectangleWithCircularHoles，外边 selector 保留原始顶点次序，孔 selector 使用到圆心的径向距离，法向调用几何的 boundary_normal。孔壁外法向是指向孔内的负径向。矩形角点使用相邻法向的归一化和，该约定不代表角点存在唯一光滑法向。

新导入路径启用可选的 stratified_boundary：先给四边及每孔各分配一点，剩余按周长分配；少于边界组数时报错。默认 False 保持旧随机采样策略。圆孔接触外框、孔之间相切/相交时前端和 Python 均拒绝。

不满足解析条件时保留 Polygon，圆孔仍经 make_circle_hole 等角重采样。界面披露分段数和圆弧弦高，不把该弦高冒充原 CAD 拟合误差。空间选择器按 dtype/坐标量级补充舍入容差，避免 float32 中短边边界点漏选。

接口职责和孔洞外法向约定参考 DeepXDE 的 CSGDifference（减去几何的边界使用反向法向）；本次为 OpenPINN 的 PyTorch 独立实现，未引入 DeepXDE 依赖，也未声称已支持通用 CSG。

08 · 条件选择、导数边界与损失生成

SampleBatch.boundary / initial
  → condition.sample_kind 选择点集合
  → Condition.select：selector 返回 N 个布尔值
  → model(selected_points)
  → evaluate_value：常数 / 张量 / 回调目标标准化
  → Condition.error / NeumannBC.error / RobinBC.error
  → weight × error²（逐点）
  → StrongFormulation.loss_terms：取均值
  → LossComposer 或自适应 composer

Condition.select 检查掩码长度；选中零点会明确报错，不会返回一个看似良好的零损失。evaluate_value 把标量、1D Tensor 和 callable 返回值变成兼容批形状。DirichletBC 继承普通 prediction−target；InitialCondition 使用 initial 样本集合。

NeumannBC.error 对筛选点保留/建立 requires_grad，计算模型梯度与归一化外法向的点积，减去目标。RobinBC.error 计算 α·prediction + β·normal_derivative − target。法向可为常量、Tensor 或 callable；时空问题应给出与坐标维度匹配且时间分量为 0 的法向。两者当前只接受输出宽度 1。

StrongFormulation 与 InterfaceStrongFormulation

residuals 调 model 和 problem.evaluate_residual；pointwise_loss_terms 形成 PDE 点平方损失和条件点平方损失，有 interior_weights 时只对内部 PDE 项乘相应权重；loss_terms 将每项取均值。相同条件名会加后缀防覆盖。

InterfaceStrongFormulation 额外要求材料界面、左右扩散系数元数据及 DomainDecompositionPINN；在界面同时计算两分支的值、导数、物理通量，添加 interface_solution 和 interface_flux 损失。它不是任意维度的通用界面算子。
