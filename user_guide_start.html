01 · 阅读方法与使用范围

核心使用流程：自定义几何 → 控制方程 → 边界条件 → 生成训练代码 → 本地运行与验证。

不必把自己的问题改成某个内置案例。先用第 03 章确认环境，再按下列路线建立自己的计算模型。

  1. 设置计算区域，或导入图片/坐标、导入 DXF。
  2. 选择模板、公式与物理参数或按项组合，确认系数与符号。
  3. 逐边设置条件及初值，区分外边界和孔洞。
  4. 核对并生成训练代码，保存脚本后独立运行。
  5. 检查物理条件及参考误差，不以预览图代替验证。

可直接跟做：一维不同端点条件 · 二维不规则区域 · 两个圆孔区域。

这份说明书只回答“如何操作 OpenPINN”。第一次使用请依次阅读安装、第一次运行、配置器操作和结果查看；需要导入图片、DXF 或 COMSOL 参考表时，再进入对应章节。所有命令除另有注明外都在项目根目录执行，即包含 pyproject.toml 的文件夹。

你的任务推荐入口应得到的结果
先确认软件能运行第 03 章的 5 步 Poisson 示例独立运行目录和有限数值输出
不想手写控制方程代码配置生成器 → 新控制方程 → 复制代码完整 Python 脚本；另行运行才开始训练
计算双隧道二维模型内置 tunnel_model1孔压时间切片、物理诊断图与指标
导入自己画的区域新控制方程 → 二维 → 图片/坐标文件或 DXF几何预览、边界设置及嵌入几何的 Python 代码
和 COMSOL 的数值结果比较训练后对比独立参考场在相同坐标直接预测后得到误差指标
网页里的彩色“示例场”不是 PDE 求解结果，也不是训练前就计算出的真实解。改变 PDE 项而示例场形状没有按预期变化，并不意味着生成代码没有变化。请同时核对公式、生成代码，以及训练结束后的结果文件。

本手册于 2026-10-16 更新 GitHub 首次安装、网页构建与下载运行步骤；此前已同步解析圆孔导入。软件包报告的版本为 0.2.0，历史工作目录名 v0.6-dev 和 GitHub ZIP 名 OpenPINN-main 都不是另一个包版本。

02 · 安装、环境检查与打开页面

2.1 先分清阅读、构建和训练

“安装”指配置 OpenPINN 的 Python 计算环境，不是安装浏览器插件。下载源码后，docs/manuals/public/user_manual.html 和 developer_manual.html 已经存在，可用浏览器离线阅读；完整配置器网站的 docs/_build/html/ 尚不存在，必须先按下方步骤生成。

需要 Python 3.10 或以上（本次 macOS 走查为 3.13.9，新手可选常规 3.13.x 安装程序）与 Node.js 24.x、版本不低于 24.15.0。下载对应系统的安装程序，而不是 Source release。Windows 安装参见 Python 官方说明。安装后重新打开终端，确认版本检查命令能输出版本号。没有 GPU 也能在 CPU 上完成首次短运行。

先完整解压项目；同时包含 README.md、pyproject.toml、src/ 和 docs/ 的文件夹是项目根目录。在 macOS 终端输入 cd 和一个空格，把项目文件夹从 Finder 拖入后按回车；执行 ls pyproject.toml 应显示文件名。Windows 在该文件夹的地址栏输入 powershell 并按回车，执行 Test-Path .\pyproject.toml 应输出 True。Linux 在该文件夹打开终端。不要照抄“你的路径”这样的占位文字。

2.2 macOS / Linux 安装

python3 --version
node --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[test,docs]"
python -c "import openpinn; print(openpinn.__version__); print(openpinn.__file__)"
python -m openpinn list-methods

安装检查应显示 0.2.0。每次新开终端，先回到项目根目录，再执行 source .venv/bin/activate。已有可靠 Conda/PyTorch 环境时可继续使用原环境，不要盲目替换 CUDA/PyTorch。命令逐行执行，遇到错误先停止，不要继续下一步。

2.3 Windows PowerShell 安装

python --version
node --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[test,docs]"
.\.venv\Scripts\python.exe -c "import openpinn; print(openpinn.__version__); print(openpinn.__file__)"
.\.venv\Scripts\python.exe -m openpinn list-methods

不需要激活环境或修改 PowerShell 执行策略。本手册后续通用命令中的 python，Windows 未激活环境时一律替换为 .\.venv\Scripts\python.exe；不要把安装依赖的解释器与运行脚本的解释器混用。首次运行的两种系统命令在第 03 章分别列出。

2.4 先生成网页，再打开

刚下载源码时找不到 docs/_build/html/ 是正常的。先完成环境安装，再构建；不用手动创建这个目录。单独阅读这份说明书不代表训练环境已经装好。

macOS/Linux（已激活环境），在项目根目录执行：

python scripts/build_docs.py
ls docs/_build/html/method_configurator.html

Windows PowerShell：

.\.venv\Scripts\python.exe scripts/build_docs.py
Test-Path .\docs\_build\html\method_configurator.html

先确认构建无报错，并输出 Documentation built:；然后检查文件，macOS/Linux 应列出文件名，Windows 应为 True。构建失败时先处理第一处错误，不要把已有旧文件当作本次成功。

  1. 构建成功后，在文件管理器进入 docs → _build → html，双击 method_configurator.html 打开配置器，或双击 index.html 打开首页。
  2. 左侧“使用者说明书”和“开发者说明书”进入站内分页阅读。不要把 docs/manuals/_sources/ 中的正文片段当作入口。
  3. 更新源码后重新执行 scripts/build_docs.py 并刷新页面；只运行 Sphinx 不会更新说明书正文。
  4. 不要只移动一个配置器 HTML，它还需要同目录的 _static 等资源。两份独立说明书可一起复制离线阅读。

当前源码包不提供 dist/ 中的 wheel 安装包，无需寻找它。检查 openpinn.__file__ 应指向当前项目的 src/openpinn；版本号相同不保证加载的是同一份源码。

03 · 第一次运行：从网页下载到看到结果

3.1 先从网页下载一个 Poisson 示例

  1. 打开配置生成器，控制方程选择 Poisson（一维） · poisson；训练步数填 5，终端输出间隔填 1，随机种子填 0，结果文件夹填 runs。
  2. 只勾选普通 PINN（baseline），其余方法不选；其他参数保持默认。不勾选“训练后对比独立参考场”。
  3. 点击“下载 .py”，得到 poisson.py。在电脑的“下载”文件夹中明确重命名为 first_poisson_run.py，再移动到项目 examples/。仓库自带 examples/poisson.py，不要覆盖它。重复下载或再次运行时也不要覆盖自己的旧脚本，若另取名字需同步修改命令。
  4. 回到项目根目录，执行对应系统的命令；不要双击 .py，不要在浏览器地址栏执行命令。

macOS/Linux（已激活环境）：

python examples/first_poisson_run.py

Windows PowerShell：

.\.venv\Scripts\python.exe examples\first_poisson_run.py

终端应出现 step=1 等日志，结束后打印“结果目录：……”。进入这个目录，用浏览器打开 result.svg 和 loss.svg，用文本编辑器查看 status.json，检查 status 为 completed、finite_outputs 为 true。仅 5 步不能保证图像拟合或物理精度；这里只验证完整流程。

3.2 可选：手写一个小预算检查脚本

已经跑通网页下载路线可跳过本节。愿意手写代码时，在项目根目录新建 my_first_run.py，保存以下完整代码：

import openpinn as op

result = op.solve(
    "poisson",
    method="baseline",
    variant="plain_pinn",
    steps=5,
    seed=0,
    model={"hidden_layers": [8, 8]},
    sampling={"interior": 16, "boundary": 8},
    training={"log_every": 1},
    output_root="runs/manual_first_run",
)
print("结果目录：", result.output_dir)
print("指标：", result.metrics)

macOS/Linux（已激活环境）：

python my_first_run.py

Windows PowerShell：

.\.venv\Scripts\python.exe my_first_run.py
  1. 终端出现 step=1 total=... 等输出。
  2. 结束时打印独立结果目录。
  3. 打开该目录的 status.json，检查状态及 finite_outputs。
  4. 打开 result.svg 和 loss.svg，再检查 metrics.json。
5 步及小网络仅检查程序能否完成，不用于判断模型精度。正式计算时调整回合适的网络、采样点与步数，并用独立参考数据或物理约束检查结果。

3.3 可选：命令行方式

python -m openpinn run --problem poisson --method baseline --variant plain_pinn --steps 5

终端最后会打印 JSON 概要。结果目录一般在当前工作目录的 runs 下。不要反复把同一个非空目录作为 --output-dir；软件会拒绝覆盖。

3.4 停止运行

在终端按 Ctrl+C 可中断当前运行。不要假定中断时一定已有最新检查点：标准实验通常在完整训练和评估后写出最终 checkpoint。重新运行默认会创建新目录。

05 · 选择内置模型

简称使用场景默认设置摘要重点查看
poisson一维静态方程与入门测试x∈[-1,1]；3 层 64 单元；内部/边界点 128/32预测与参考曲线、绝对误差、相对 L2
burgers一维空间、含时间的非线性问题x∈[-1,1]，t∈[0,1]；4 层 64 单元；256/64/64时间切片、参考误差、初值和边界误差
tunnel_model1双隧道二维模型（孔压固结）40×40 m，0–40 年；512/256/256二维孔压场、PDE 残差、孔压消散、物理范围
heterogeneous_poisson一维两种材料的界面问题界面 0；左右扩散系数 1 与 4；3 层 32 单元界面值跳跃及通量跳跃
coupled_manufactured检查多输出、多残差工作流程制造解测试问题，3 层 32 单元各场独立误差，不只看总指标

表中采样数量按“内部 / 边界 / 初值”顺序。只有含时间问题需要初值点。它们是短 API 的默认值，不代表对所有问题最优。相同模型名称在自定义 YAML 或生成脚本里可能已被覆盖。
