十类改进方法详解

OpenPINN 已提供网络结构、激活函数、Fourier 特征、硬边界约束、 自适应权重与采样、组合优化器、时间窗、迁移学习和区域分解等方法。 每个方法页都给出调用方式、适用案例、对照设置、参考实验和已知限制。

统一选择方式

所有方法使用同一个入口。method 选择方法大类，variant 选择该大类中的 具体实现：

import openpinn as op

plain = op.solve(
    "poisson", method="baseline", variant="plain_pinn", steps=5000
)
improved = op.solve(
    "poisson", method="fourier", variant="random_fourier", steps=5000
)

也可以运行 python -m openpinn list-methods 查看家族，再用 python -m openpinn list-methods --family adaptive_sampling 查看具体变体。 configs/methods/ 按方法家族建立文件夹并保存变体默认值， configs/problems/ 保存问题设置；configs/reference_runs/ 中的“问题+方法”配置只是已经完成的公平对比记录，不是日常用户必须复制的入口。

省略 variant 时仍使用当前默认实现，所以旧代码不需要修改。十类是功能家族， 不是把具体算法数量锁死为十个；自适应采样和损失平衡家族现在已经有多个平行变体。

全部家族、具体变体、中文名称、适用方向和论文原文统一列在 方法简称总表。该页面由 docs/method_catalog.yaml 自动生成， 不再在多个文档中手工维护重复表格。

增加同一家族的第二种方法

例如第二种自适应采样不应再建立一套训练器，而应增加平行文件：

src/openpinn/methods/adaptive_sampling/
├── residual_adaptive.py
└── 新方法简称.py

configs/methods/adaptive_sampling/
├── residual_adaptive.yaml
└── 新方法简称.yaml

同时增加 tests/methods/adaptive_sampling/、对应方法说明和正式结果。没有论文、 算法定义或许可边界时，不把占位名字冒充成已经实现的方法。

阅读方法页时建议关注七项信息

  1. 作用：它希望解决训练困难、高频解、非均质、长时间计算还是其他问题；

  2. 依据：记录主要论文、公式和参考代码链接；

  3. 使用方法：说明需要修改哪个设置、运行哪条命令；

  4. 适用案例：Poisson、非均质 Poisson、Burgers 或后续波动方程；

  5. 普通方法：保留一份普通 PINN 设置作为对照；

  6. 结果：保存误差、残差、时间、硬件、图表和随机种子；

  7. 问题：如实记录没有提升、运行失败或不适用的情况。

比较方法的推荐流程

  1. 先运行普通 PINN 短案例；

  2. 复制一份配置，只改变目标方法需要的设置；

  3. 实现方法并增加小测试；

  4. 运行改进方法短案例，确认输出都是有限值；

  5. 再进行较长训练；

  6. 把两组结果放在同一张表或同一张图中；

  7. 运行全部测试，确认旧案例没有被破坏。

新增二级变体

同一家族可以继续增加任意数量的二级变体，不受“十类方法”数量限制。新增记录后， 方法简称总表 会自动把相同 method 合并在一起，并把 variant 链接到 对应详情页；完整步骤也写在该页面底部。
