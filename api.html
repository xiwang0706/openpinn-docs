solve(problem, *, method=None, variant=None, methods=None, steps=1000, seed=0, device='cpu', dtype='float32', method_options=None, problem_options=None, model=None, sampling=None, training=None, overrides=None, output_dir=None, output_root='runs', run_name=None, plot=True)

Train one built-in or user-defined PDE using method shorthands.

示例

solve("poisson", method="fourier", variant="random_fourier", steps=500)

Independent improvements can be composed with methods=[method("fourier"), method("adaptive_weights", "relobralo")]. A component-slot conflict is rejected before training starts.

For a new equation, construct PDEProblem once and pass that object in place of the built-in problem name.

evaluate_reference_csv(result, path, *, coordinate_columns=('x',), value_column='u', problem=None, field_index=0, coordinate_scales=None, value_scale=1.0, prediction_scale=1.0, time_axis=None, fixed_time=None, batch_size=4096)

Compare an independent CSV/COMSOL Spreadsheet field and save artifacts.

coordinate_columns must follow model input order (for example x,y,t). Named headers and 1-based selectors such as "#1" are supported. A COMSOL Spreadsheet table may have % comment lines and no header; comma, semicolon, tab and whitespace separators are recognized. For one exported time slice without a time column, pass spatial columns and fixed_time in the exported time unit; its scale is still the last entry of coordinate_scales. Coordinate scales convert exported coordinates into model input units. value_scale and prediction_scale independently convert the exported and model values into the same reported physical unit. All supplied coordinates must belong to problem.domain when supplied; out-of-domain samples fail loudly instead of biasing metrics by filtering.

参数:

  • coordinate_columns (Sequence[str | int])

  • prediction_scale (float)

  • time_axis (bool | None)

class Polygon(vertices, holes=())

A validated two-dimensional polygon with optional polygonal holes.

The outer ring may be convex or concave. Rings are automatically normalised to counter-clockwise orientation for the outer boundary and clockwise orientation for holes, so boundary_normal() consistently returns the outward normal of the computational domain. The class has no optional geometry dependency and can also read CSV, JSON, and GeoJSON polygon files via from_file().

参数:

  • holes (tuple[tuple[tuple[float, float], ...], ...])
