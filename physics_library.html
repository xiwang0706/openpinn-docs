物理参数库与安全单场公式

物理参数编辑器用于定义一个标量未知场的控制方程，把公式、参数数值和单位一起 写入生成的 Python 代码。它与配置器中的几何、边界条件和训练方法配合使用； 仅导入一个物理参数包或方程工程文件，并不能恢复完整的训练工程。

先试一个完整流程

  1. 打开 配置生成器，选择“新控制方程”，设为“含时间方程”和“二维”。

  2. 方程编辑模式选“公式与物理参数（推荐）”，在物理模板中选“二维各向异性固结（cx / cy）”， 点击“替换当前物理设置”。模板不会自动修改问题的维度或静动态类型。

  3. 在前面的公式区核对方程，在“当前参数”中修改 cx、cy 的数值与单位， 再检查下方代码中的 PHYSICS_SPEC。已有模板参数不需要再从参数库添加一次。 几何可继续使用矩形、解析圆孔或原有导入功能。

  4. 按实际问题设置边界、时间范围和初值；统一初始孔压可选“常数初值”。 核对初值与初始时刻边界是否相容。选定方法后下载 Python 文件，在本地运行。

常见定义涵盖通用量、渗流、固结、热学和弹性参数；模板包括一维固结、 二维各向同性固结、二维各向异性固结、稳态 Darcy 水头和热传导。 可选项目以当前页面的下拉列表为准。参数定义存在，不代表对应的多场求解接口也已实现。

只想选择压力等未知场时，使用“物理场预设”，选择所需场后点击“使用所选物理场”， 再核对场符号、单位和公式。物理场不是固结系数等常数参数，不应从参数库中添加。 使用预设不代替设置控制方程、几何、初值和边界；加载方程模板还会替换公式与参数， 应在修改前区分这两个操作。

测试别人提供的参数包，可展开“导入与导出”，导入 场地扩散参数演示包： 再展开添加参数区域，在“材料参数组”选择“演示场地参数”，点击“追加材料参数”，然后把公式改为 dt(p)-dx(cx_site*dx(p))-dy(cy_site*dy(p))。 包内 0.2 和 0.1 的单位是 m^2/year，仅为功能演示数值，不能用于工程结论。 旧的 cx/cy 可移除；未引用的参数不会自动参与公式计算。

水压力场与固结系数：输入二维孔压扩散方程

若你的方程是 ∂u/∂t = cx · ∂²u/∂x² + cy · ∂²u/∂y²， 不需要去参数库寻找“压力的二阶导数”。u 是未知场，cx 和 cy 是 扩散系数；导数由公式中的求导运算表示。

在“添加参数”的常用参数库中，选择“固结”分类，可找到 “固结系数（各向同性 / 一维）”“x方向固结系数”和“y方向固结系数”。 加载一维或二维各向同性模板会带入 cv；二维各向异性模板会带入 cx、cy，不必重复添加。这些系数的单位为长度平方/时间， 不是单位为长度/时间的导水率；示例值必须换成自己问题中的实际值。

  1. 先把问题设为“二维”和“含时间方程”，进入“公式与物理参数（推荐）”。

  2. 加载“二维各向异性固结”模板以带入方程和两个系数；场变量符号改为 u， 移出输入框后公式中的 p 会同步改名，显示如下式。场单位按实际压力单位设置。

    dt(u) = cx * dx(dx(u)) + cy * dy(dy(u))

  3. 在“当前参数”中填写 cx、cy 的实际数值与扩散系数单位， 如 m^2/s 或 m^2/year。不要把系数与导数相加成 cx+cy。

  4. 检查公式预览、校验提示和生成代码，再单独设置计算区域、时间范围、初值与边界。

也可在公式框中放好光标，点击 ∂u/∂t、∂²u/∂x² 或 ∂²u/∂y² 按钮直接插入对应导数；按钮中的场符号跟随“未知场”设置变化。 选中一段表达式后点击导数按钮，会对选中的整段表达式求导， 例如选中 cx*dx(u) 后点击 x 一阶导数可得到 dx(cx*dx(u))。 一维时 y 导数不可用，静态时 t 导数不可用；应调整问题结构，而非把导数当作新参数添加。

模板默认用 p 表示孔压，并采用等号形式 dt(p) = cx * dx(dx(p)) + cy * dy(dy(p))。当 cx、cy 为常数时， 它与散度形式 dt(p)-dx(cx*dx(p))-dy(cy*dy(p))=0 等价；空间变系数时， 不能未经推导就把系数移到导数外。变量改名只替换完整变量符号，不会改写参数或函数名。

常用操作与高级信息分开

编辑顺序为“模板与场单位 → 导数按钮、公式与预览 → 当前参数”。 当前参数默认只展示名称、公式符号、数值和单位；名称用于阅读， 公式使用的是符号，不是名称或 id。

每行的高级信息保存参数 id、说明和来源，默认折叠。 id 用于参数包中的唯一引用，不参与求导，也不用写进公式。 一般使用不必改动；需要维护或分享参数定义时再展开核对。

需要补充系数时，展开添加参数区域，从常用参数库选择、创建自定义参数， 或追加材料参数组。新增自定义参数可以不填写 id，编辑器会根据符号生成 custom.<符号> 形式的标识，并避开已占用标识；同一方程中的符号仍须唯一。 导入、导出集中在另一个默认折叠区域，日常编写公式不需要先操作文件。

定义、数值与模板分别保存

三类物理数据

层次

保存什么

使用时需要确认什么

参数定义

参数的标识、名称、符号、分类、单位和含义。

定义不代表某种材料的实测值；未填写的值不能用于生成可运行方程。

材料数值

某个具体材料或工况使用的参数值及其说明。

材料名称、试验条件、适用范围和数据来源必须与实际问题一致。

方程模板

一个公式、所需参数、未知场及坐标单位的示范组合。

内置模板的示例值只用于演示；应用前必须核对物理假设。

训练步数、学习率、网络宽度、采样点数以及方法变体的设置仍由原来的 method_options 和训练配置管理。物理参数不会自动变成训练超参数， 也不会因为选择了某种优化方法而自动改变材料值。

从模板开始

  1. 在新控制方程的配置区域打开物理公式编辑器，选定一维/二维以及静态/动态结构。

  2. 选择一维/二维固结、稳态 Darcy 或热扩散示范模板，或从已有参数定义中选择所需参数。

  3. 核对未知场名称和单位、坐标单位、每个参数值及其单位，再编辑残差表达式。

  4. 阅读语法、量纲和维度检查结果；通过后检查生成的 Python 代码。

  5. 单独核对几何、边界、初值和训练配置，先完成短步数运行，再做参考解对照。

应用模板会替换编辑器内的物理公式、未知场、参数和单位。 模板中的初值/边界值是文字建议，不会改写现有几何、边界或初值。 如果模板与原来的空间维度或静态/动态结构不同，应先调整问题结构， 再核对原有区域和约束是否仍然适用。

公式支持范围

公式可写成 左侧 = 右侧，或只填写 残差 = 0 的左侧。 当前入口面向一维或二维、静态或含时间的 单个标量场；字段名称由编辑器中的未知场设置决定，不要求固定写成 u。

可使用数值、已定义参数、当前问题的坐标、未知场、括号以及受支持的运算与函数。 dx(...)、dy(...)、dt(...) 表示对相应物理坐标求导。 例如 dx(dx(p)) 是二阶空间导数，dy(dx(p)) 是混合空间导数。 一维问题不能使用 y 或 dy；静态问题不能使用 t 或 dt。 求导嵌套总阶不超过二阶；dt(dt(p)) 被拒绝，因此此入口不提供波动方程 所需的二阶时间导数及初始速度配置。

表达式经过限定语法树检查，不是任意 Python 或 JavaScript 程序。 导入文件不能携带可执行函数、模块导入、文件访问或网络操作。 标识符必须已定义，参与相加减的项必须具有相容量纲。 通过语法和量纲检查仍不代表方程物理正确，也不代表一定能收敛。

参数记录保存常数。需要连续空间变系数时，应把坐标依赖写进表达式， 例如用已定义的常数构成 k0 * (1 + x / L)，其中 L 是长度参数。 若写散度形式，应明确把系数放在导数内，如 dx(k0 * (1 + x / L) * dx(p))。 该写法不能代替多区域材料界面条件，也没有提供材料分区表或任意分段函数。

此入口不支持多未知场 Biot 耦合系统、任意向量/张量场和自动生成物理通量边界。 已有配置器的 Neumann 条件约束外法向导数；若模型需要 -k * dp/dn 这样的通量，应单独推导并实现相应边界，不能直接把导数值当成通量。 这些限制仅说明当前安全公式入口的能力，不等于 Python 核心无法扩展其他模型。

单位是计算规则

单位目录中的每个单位有一个到 SI 的乘法系数 factor，以及按 [M, L, T, Theta] 排列的质量、长度、时间、温度量纲指数。 当前采用明确列出的单位，不把任意输入字符串当作可解析单位表达式。 具有加性偏移的单位不能仅靠乘法系数表示；温度计算应使用支持的绝对温标。

几何和网络输入保留配置器中填写的原始数值。残差内部按以下规则求值：

  • 坐标的物理值为 原始坐标 × 坐标单位 factor；

  • 未知场的物理值为 网络输出 × 场单位 factor；

  • 参数的物理值为 参数值 × 参数单位 factor；

  • 每次对物理坐标求导，都再除以该坐标的 factor；

  • 返回的残差按 SI 单位表达。

二维的 x、y 必须使用相同单位。改变单位选择不会自动缩放已填写的 几何数值；例如把长度单位由 m 改为 cm 后，数值 1 表示的是 1 cm。这与把同一物理长度从 1 m 改写成 100 cm 是两种操作。

以压力扩散残差为例：

dt(p) - D * (dx(dx(p)) + dy(dy(p)))

若坐标用 cm，时间用 day，压力用 kPa，扩散系数用 m^2/year``（界面也可能显示为 m²/year），则 ``p 先乘 1000， 空间坐标先乘 0.01，时间先乘 86400。因此 dx(p) 对应 1000 / 0.01 倍的原始网络导数， dx(dx(p)) 对应 1000 / 0.01^2 倍， dt(p) 对应 1000 / 86400 倍。 D 按单位目录中一年的秒数转换为 m^2/s，不能把数值直接当成 SI 系数。 最终各项量纲相同，残差为 Pa/s。

请按原始场单位填写和核对边界/初值。物理编辑器不替已有边界做新的单位换算， 也不会为残差与边界损失自动选择无量纲化或权重。SI 残差与原始场单位的 边界损失可能有不同数值尺度，应结合实际模型检查训练尺度。

离线导入、导出与迁移

参数包

schema_version: 1 的 JSON 数据包，包含 parameters 和 materials。它用于共享参数定义及材料记录，不允许定义新单位、 方程模板或可执行代码。导入时先检查整包；发生错误时保留导入前状态。 定义使用 value: null；材料记录用参数 id 引用定义，并单独填写 value、unit 与来源。重复导入完全相同的定义会复用，但冲突的定义或重复 材料 id 会报错。不同定义可使用同一建议符号，加入同一个方程时必须改为唯一符号。

方程工程

保存当前公式的安全语法树、公式源文字、未知场、维度/类型、坐标单位及 参数值。这个快照仅覆盖方程和物理参数，不包含几何、边界、初值、训练方法、 checkpoint 或训练结果。导入错误时不应覆盖原有方程和参数。

生成代码

包含所需的完整物理 spec。把生成的 Python 文件移到安装了兼容版本 OpenPINN 的另一台电脑后，无须再携带当初导入的参数包 JSON。 外部参考场、用户另写的代码和其他自行添加的文件仍需按各自路径管理。

导入和导出均在本地完成。选择文件不等于向社区上传；本项目没有通过此功能 接收参数包的远端服务。需要保存编辑进度时，请显式导出文件，不要把浏览器页面 视为完整项目备份。

读取默认内置目录，或读取指定路径的目录数据。

validate_physics_catalog(data)

检查目录结构、单位、参数和模板等数据。 这里校验的是完整目录（含 categories/templates），不是浏览器的三字段参数包。

validate_physics_spec(spec)

检查单个方程规格，包括字段、参数、维度、表达式和单位。

make_physics_residual(spec)

根据已验证的规格建立可交给 PDEProblem 使用的残差函数。 调用它本身不创建几何或边界，也不开始训练。

spec 使用 schema_version: 1，包含 dimension、kind、 field、field_unit、coordinate_units、expression 和 parameters。kind 为 static 或 dynamic； expression 是安全语法树，expression_source 可保存可读公式文字。 请从编辑器导出规格或复制模板，不要把普通公式字符串直接填入 expression 来替代语法树。

贡献与验收

社区贡献应以数据文件的 Pull Request 提交，由维护者审查定义、单位、来源和 适用范围，再执行目录/规格校验、自动化测试和文档构建。 参数数据更新不能附带任意执行代码，也不会由离线页面自动进入公共目录。 贡献约定见仓库 catalog/README.md，独立验收项目见 catalog/ACCEPTANCE.md。验收计划列出应达到的标准；实际通过情况以对应 测试输出和人工检查记录为准。
