几何创建、导入与编辑

设置区域，导入图片或 DXF，编辑顶点和圆孔。

区域确定后，返回 自定义建模与代码生成 设置控制方程、边界与初值并生成代码； 已有脚本则进入 训练设置与运行。本页只处理几何，不会自动完成 PDE 求解。

07 · 直接设置一维、矩形和曲线区域

几何选项填写内容操作检查
一维x 下限和上限图中横轴为 x，曲线纵向为示例 u，不是第二个空间方向
矩形x/y 四个上下限上下左右边界与轴标是否对应
圆形圆心 x、y；半径 R>0直径是 2R；直接圆形区域并不是“矩形中的圆孔”
椭圆中心、半轴 a、b；逆时针旋转角（度）a、b 是半轴，不是全轴长；a=b 时为圆
圆角矩形坐标范围及圆角半径 r0≤r≤短边一半；r=0 退化为直角矩形
可编辑闭合曲线控制点与张力 0–1拖动后检查闭合、自相交与细窄部位

7.1 椭圆 a、b 的使用

不旋转时，几何满足 ((x−cx)/a)² + ((y−cy)/b)² = 1。例如 a=2、b=1，横向总宽为 4、纵向总高为 2。旋转改变方向，不改变两个半轴长度。a 只是局部 x 半轴，不强制必须大于 b。

7.2 曲线张力不是曲率

张力为 0 时更圆滑，接近 1 时更贴近控制折线。张力不等于数学曲率 κ，也没有固定物理单位；不能把张力 0.2 解释为曲率 0.2 m⁻¹。需要严格圆弧时优先直接使用圆/圆角几何，需要沿轮廓的复杂形状时使用闭合曲线。

7.3 原点与坐标

查看坐标范围、轴名和原点标识；如果 (0,0) 本来在当前计算范围之外，不要为了显示原点而误改几何。改变 Dirichlet 值改变的是边界上的场值 u，不会把二维几何的 y 坐标整体平移。

08 · 从图片或坐标文件导入区域

8.1 图片操作步骤

  1. 选择“导入多边形文件（识别图片）”，选择 PNG/JPG。
  2. 尽量使用裁剪干净的填充色块图：外背景与实体区域可区分，孔洞使用背景色；避免尺寸标注、文字、阴影或其他图形接触轮廓。
  3. 先使用自动前景、自动二值化、1024 px 识别分辨率。
  4. 填写用于像素映射的 x/y 物理坐标范围。它不是自动测得的工程尺寸，导入后必须核对宽高比例和实际边长。
  5. 点击“按当前设置重新识别”，查看外轮廓、孔洞数量以及提示。
  6. 若细孔或细边丢失，提高分辨率或降低拐角简化量；若像素阶梯产生很多点，适当提高简化量。
  7. 识别完成后编辑轮廓、设置边界并复制代码。
设置如何使用
前景色自动、深色区域、浅色区域；若识别到了背景而非实体，切换前景模式后重新处理
手动阈值1–254，默认输入 128；用于自动分色不适合的图片，不是固定“只识别黑色”的开关
识别分辨率384、768、1024、1536、2048 px 上限；越高更慢，无法恢复原图中已经丢失的信息
拐角简化0.25–5 px，默认 2；小值保留更多细节，大值减少碎点但可能抹去小差异
曲线模式自动、强制可编辑曲线、始终多边形、强制圆、强制圆角矩形；强制拟合并不证明原图严格满足该几何

自动模式可处理灰色、彩色区域以及透明背景，并检查连续转向以选择曲线或拐角表示；带孔图片继续使用多边形表示。当前算法选择主要连通区域，不适合在一张图中导入多个彼此分离的计算域。识别结果必须人工核对，不能把“自动”理解为工程级无损重建。

8.2 坐标文件操作

同一入口也支持 CSV、JSON 和 GeoJSON Polygon。一个文件描述一条外轮廓及可选孔洞；不支持 MultiPolygon。每个环至少三个不重复有效顶点；不得自相交，孔洞必须在外轮廓内，不得互相重叠或穿出边界。

ring,x,y
outer,0,0
outer,4,0
outer,2,3
{
  "outer": [[0,0], [4,0], [4,4], [0,4]],
  "holes": [[[1,1], [1,2], [2,2], [2,1]]]
}

GeoJSON 使用 Polygon 的外环、内环结构；其标准闭环会重复首尾坐标。导入后会进行标准化。网页单文件限制 5 MB，每个边界环最多 5,000 个顶点；超大工程图应先提取真正的计算区域。

五角星有 5 个外尖角，但完整轮廓通常还有 5 个凹角，共 10 个关键顶点。不要为了只剩 5 个点而丢掉凹角；应去掉的是像素阶梯碎点。

09 · 导入 COMSOL / CAD 的 DXF 几何

9.1 接受与不接受的文件

选择“导入 DXF 图纸（COMSOL/CAD）”。这里要求二维 ASCII DXF。CAD 是软件/设计类别，不是必须使用的扩展名。.dxf 是交换格式，.dwg 与 COMSOL 的 .mph 原生工程文件不能直接读取，也不能只改后缀变成 DXF。

图纸实体当前处理方式
闭合 LWPOLYLINE / POLYLINE读取轮廓及圆弧 bulge 信息
CIRCLE、完整 ELLIPSE转换成可预览、可训练的边界表示；DXF 路径仍可能离散
LINE、ARC、开放多段线、椭圆弧要求能无缺口、无分叉地拼成闭环
SPLINE需要完整控制点和节点数据；只有拟合点的形式不支持
块引用、3D、多块不连通区域不支持；先在原软件整理为所需的二维闭合计算区域

9.2 导入步骤

  1. 在来源软件中准备计算区域的二维几何交换文件，不要把解场截图当成 DXF。
  2. 选择文件并填写“图纸单位→模型单位”的换算系数。例如毫米转米填 0.001。
  3. 检查状态栏的坐标范围、实体/孔洞数量与 $INSUNITS。未声明单位不意味着一定是米。
  4. 核对外轮廓边长与孔洞位置。确认孔洞是真正空区域，不是多个叠加外轮廓。
  5. 选择外轮廓或某个孔洞，调整尺寸并设置边界条件。
  6. 复制生成代码；运行时几何坐标已嵌入脚本，一般不需要再次读取原 DXF。

如来源软件没有你所需的导出选项，请先核对版本和可导出格式；此导入器不提供 MPH→DXF 转换。COMSOL 参考场数值表的导入走第 14 章，和几何导入是两项独立操作。

9.3 测试文件

项目提供 examples/geometries/comsol_2d_export_example.dxf（矩形与八边形孔洞）、cad_l_shape_example.dxf（L 形区域）和 rectangle_with_hole.dxf。这些是交换格式测试样例，不应当作完整原生 COMSOL/CAD 工程文件。

10 · 编辑顶点、边长、圆孔尺寸及编号

10.1 先选对正在编辑的边界环

在醒目的“选择要编辑的外轮廓 / 孔洞”下拉框中选择对象。图内的“孔洞 1”“孔洞 2”与这个下拉框、边界条件行保持一致。编号是导入后的顺序，不保证左边一定是孔洞 1；重新导入另一文件后必须按图核对。

10.2 普通多边形

  1. 选择外轮廓或某个非圆孔。
  2. 在图中拖动顶点，或者在表格中输入该顶点 x/y 坐标。
  3. “到下一顶点的边长”对应 i→i+1，最后一点连回第一点；修改会移动相关顶点，也可能改变邻接边。
  4. 修改内角、插入或删除顶点后，重新核对编号和对应边界条件。它不是能同时锁定所有长度、角度的 CAD 约束求解器。
  5. 若提示自相交、孔洞越界或重叠，不要忽略；先把轮廓恢复到有效状态。

10.3 已识别的 DXF 圆孔

  1. 选择“孔洞 N（圆形）”。
  2. 输入圆心 x、圆心 y、半径 r 或直径 D；D=2r。
  3. 完成输入并提交字段（回车或移出输入框）后核对预览。该编辑器的部分字段按 change 事件提交，不保证打字每个字符都立即生效。
  4. 图内显示孔洞编号和 D；当前圆孔以蓝色虚线突出。
  5. 检查生成代码中的 HOLE_N_CENTER_X、HOLE_N_CENTER_Y、HOLE_N_RADIUS 已更新。
圆孔识别不是把所有看起来像圆的对象无条件改成圆。对椭圆或粗糙轮廓不要强行使用圆的解释。只有四顶点轴对齐矩形＋全部圆孔走解析训练路径；其他情况保留多边形近似。提示中的圆孔弦高 r*(1-cos(π/N)) 只衡量等角点列相对拟合圆的离散误差，不衡量拟合圆相对原图的识别误差。拖动外框变成非矩形后，请重新检查“训练几何”提示与生成代码。

10.4 整体变换与恢复

可以填写旋转角、X/Y 缩放、X/Y 平移后点击“应用整体变换”。操作会影响整个导入区域，先确认所有孔洞都应一起移动。非等比例缩放会改变圆的形状，之后应重新检查是否仍被当作圆孔。点击“恢复刚导入的轮廓”前，先保存需要保留的生成代码；恢复会撤销本次几何调整。

10.5 修改后的核对顺序

依次核对：图中形状 → 顶点/孔洞编号 → 边界条件对象 → 代码中的坐标与条件 → 5 步运行输出。对一份已经复制到编辑器里的脚本，后来修改网页不会自动回写；必须重新复制保存。
