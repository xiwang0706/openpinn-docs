不确定性权重（uncertainty_weighting）

方法速览

调用简称:

method="adaptive_weights"，variant="uncertainty_weighting"

简单介绍:

为每项损失学习对数方差，用 exp(-s) 自动缩放不同任务并用正则项防止权重塌缩。

适用方向:

多项损失尺度或噪声水平差异明显的问题；不等同于“误差越大权重越大”。

论文原文:

Multi-Task Learning Using Uncertainty to Weigh Losses for Scene Geometry and Semantics

代码与许可:

OpenPINN 按公开公式独立实现；未复制外部代码。

超参数怎么改

op.method(
    "adaptive_weights",
    "uncertainty_weighting",
    lr=0.001,
    min_log_variance=-10.0,
    max_log_variance=10.0,
)

参数

默认值

含义与修改影响

对数方差学习率 lr

0.001

学习各损失项对数方差时的学习率。 调大使任务权重变化更快但更易波动；调小变化更平滑，但适应速度更慢。

最小对数方差 min_log_variance

-10.0

对数方差参数的下界。 设得更小允许更大的实际权重 exp(-s)，也增加数值过大风险；提高下界会限制最大权重。

最大对数方差 max_log_variance

10.0

对数方差参数的上界。 设得更大允许把高不确定项降得更低，也可能近似忽略该项；降低上界可避免过度降权。

建议先保留默认值完成短跑，再一次只改一个参数并记录误差与时间。也可以在 配置生成器 中选择方法后直接编辑这些参数；调大或调小都不保证精度一定提高。

大白话

每个损失项学习一个对数方差 s，实际系数是 exp(-s)。持续表现为高噪声/ 高不确定性的项会被降权，同时 +s 防止所有权重无限缩小。它不是 SA-PINN 的 “难点自动变重”机制。

放在哪里与怎么调用

核心在 losses.py 的 UncertaintyLossComposer；二级入口为 methods/adaptive_weights/uncertainty_weighting.py。

result = op.solve(
    "poisson", method="adaptive_weights",
    variant="uncertainty_weighting", steps=5000,
)

论文、代码与许可

依据 Kendall, Gal and Cipolla (2018), Multi-Task Learning Using Uncertainty to Weigh Losses for Scene Geometry and Semantics, arXiv 1705.07115，以及 Hou et al. (2023) 在 PINN 中采用的相同形式。实现按公式独立编写，未复制代码。

300 步参考短跑

普通/改进相对 L2 为 0.44732/0.29337，PDE 残差为 1.35361/1.33685， 用时 0.1558/0.1701 s；最终 PDE/边界系数为 0.90697/1.06661，新增 2 个参数。 结果位于 results/method_expansions/20260829/adaptive_weights/uncertainty_weighting/。
