顺序时间窗：先学早期，再打开后期

方法速览

调用简称:

method="time_window"，variant="causal_window"

简单介绍:

从早期时间段开始训练，再逐步扩展到完整时间域，降低后期状态反过来干扰早期学习的风险。

适用方向:

包含时间维度、长时间或强非线性的动态问题；不适用于纯静态方程。

论文原文:

Respecting causality for training physics-informed neural networks

代码与许可:

参考代码；CC BY-NC-SA 4.0 且仓库声明专利边界；OpenPINN 的顺序时间窗不是该算法复刻。

超参数怎么改

op.method(
    "time_window",
    "causal_window",
    window_ends=[0.25, 0.5, 0.75, 1.0],
)

参数

默认值

含义与修改影响

时间窗终点 window_ends

[0.25, 0.5, 0.75, 1.0]

按顺序扩展训练区域时使用的归一化时间终点。 增加窗口数量会让因果推进更细但重采样阶段更多；减少窗口更简单。数值必须递增，最后通常为 1.0。

建议先保留默认值完成短跑，再一次只改一个参数并记录误差与时间。也可以在 配置生成器 中选择方法后直接编辑这些参数；调大或调小都不保证精度一定提高。

这是什么

普通动态 PINN 从第一步就在全部 t in [0, 1] 采样。时间窗版先只在 [0, 0.25] 训练，之后依次扩大到 [0, 0.50]、[0, 0.75] 和 [0, 1.00]。 每次仍保留从初始时刻到当前上限的数据，避免只学新时间段而完全丢掉早期。

放在哪里

  • 时间窗采样器：src/openpinn/sampling.py 的 TimeWindowSampler；

  • 统一调用：sampling.name: time_window；

  • 时窗端点：sampling.options.window_ends；

  • 对比入口：examples/burgers_time_window.py。

许可和专利边界

  • 核心论文：Wang, Sankaran and Perdikaris, Respecting causality for training physics-informed neural networks, Computer Methods in Applied Mechanics and Engineering 421 (2024) 116813， DOI 10.1016/j.cma.2024.116813。

  • 参考仓库 https://github.com/PredictiveIntelligenceLab/CausalPINNs 明确说明算法受 宾夕法尼亚大学专利保护，代码/材料采用 CC BY-NC-SA 4.0，不当作可商用代码。

  • 本项目没有复制、改写或启用该仓库的指数因果权重。这里是独立编写的通用 时间域课程，不是论文专利算法的复刻。

最短调用

import openpinn as op
result = op.solve(
    "burgers", method="time_window", variant="causal_window", steps=5000
)

怎么跑

PYTHONPATH=src python -m examples.burgers_time_window \
  --output-dir runs/burgers_time_window_<timestamp>

公平对比

两组使用相同 Burgers 问题、随机种子、512/64/64 个内部/边界/初值点、 64×4 MLP、损失、Adam 和 1500 步，都每 375 步重采样。普通组每个阶段都采样全时域； 时间窗组在三次更新中逐步打开后续时间。

参考实验结果

2026-08-26 在 CPU 上使用固定随机种完成 1500 步对比。两组都运行完成， 时间窗组完成三次更新并到达 t=1，保存数值、checkpoint、诊断与 SVG 均通过检查。 Cole–Hopf 参考解只用于训练后评价。
