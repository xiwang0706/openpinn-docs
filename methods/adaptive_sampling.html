自适应采样：训练点怎么随模型变化

方法速览

调用简称:

method="adaptive_sampling"，variant="residual_adaptive"

简单介绍:

周期性计算候选点 PDE 残差，并按残差分布重新选择整批内部训练点。

适用方向:

误差集中在局部区域、均匀采样浪费训练点且允许周期性重选点的问题。

论文原文:

A comprehensive study of non-adaptive and residual-based adaptive sampling for physics-informed neural networks

代码与许可:

参考代码；Apache-2.0；OpenPINN 按论文描述独立实现 RAD 风格采样器。

超参数怎么改

op.method(
    "adaptive_sampling",
    "residual_adaptive",
    candidate_pool=512,
    power=1.0,
    uniform_mix=0.1,
    epsilon=1e-12,
    resample_every=50,
)

参数

默认值

含义与修改影响

候选点数量 candidate_pool

512

每次重采样前用于评估残差的候选内部点数量。 调大覆盖更充分、找到难点的机会更高，但每次重采样更耗时和内存；调小更快但选择更粗糙。

残差幂指数 power

1.0

残差转为抽样概率时使用的幂指数。 调大更集中采样高残差区域，可能丢失全局覆盖；调小使分布更接近均匀，适应性减弱。

均匀采样混合比例 uniform_mix

0.1

保留均匀覆盖的概率比例。 调大增强全域探索但减少难点聚焦；调小更集中高残差点，也更容易遗漏其他区域。

数值稳定量 epsilon

1e-12

残差转概率时避免全零的极小正数。 通常保持默认；调大使概率更均匀，过大可能淹没残差差异；过小在全零附近保护较弱。

重采样间隔 resample_every

50

每隔多少个外层训练步更新一次内部点。 调小会更频繁追踪当前误差但增加采样开销和波动；调大更省算力，但训练点可能更新不及时。

建议先保留默认值完成短跑，再一次只改一个参数并记录误差与时间。也可以在 配置生成器 中选择方法后直接编辑这些参数；调大或调小都不保证精度一定提高。

本家族不再只有一种算法。旧默认 residual_adaptive 保持不变；新增 RAM、WAM 和带逆概率修正的重要性采样。它们共用训练器，但各有独立二级源码、配置、测试、 文档和结果目录。

  • RAM 残差配点移动（residual_movement）
  • WAM 梯度配点移动（gradient_movement）
  • 损失重要性采样（importance_sampling）

原有默认：残差自适应重采样

这是什么

均匀采样不看网络当前学得怎么样。本方法每隔若干步先均匀生成一个更大的候选池， 计算每个候选点的 PDE 残差，然后按残差大小分配抽样概率。内部训练点总数不变， 只改变它们在时空域中的分布。

放在哪里

  • 采样器：src/openpinn/sampling.py 的 ResidualAdaptiveSampler；

  • 每次重采样前的残差更新：src/openpinn/training.py；

  • 统一调用：sampling.name: residual_adaptive；

  • Burgers 对比入口：examples/burgers_adaptive_sampling.py；

  • 固定配置：configs/reference_runs/burgers_adaptive_sampling.yaml。

依据与许可

  • 核心论文：Wu et al., A comprehensive study of non-adaptive and residual-based adaptive sampling for physics-informed neural networks, Computer Methods in Applied Mechanics and Engineering 403 (2023) 115671， DOI 10.1016/j.cma.2022.115671。

  • 参考仓库：https://github.com/lu-group/pinn-sampling，许可为 Apache-2.0。

  • 本项目只按论文描述独立编写一个 RAD 风格的概率采样器，没有复制或改写参考仓库代码。

最短调用

import openpinn as op
result = op.solve(
    "burgers",
    method="adaptive_sampling",
    variant="residual_adaptive",
    steps=5000,
)

怎么跑

PYTHONPATH=src python -m examples.burgers_adaptive_sampling \
  --output-dir runs/burgers_adaptive_sampling_<timestamp>

公平对比

两组使用相同的 Burgers 方程、随机种子、64×4 MLP、损失、Adam、1500 步、 512 个内部点、64 个边界点和 64 个初值点，都每 50 步重采样。普通组均匀重采； 自适应组从 2048 个候选点中按残差概率重选，并保留 10% 均匀探索成分。 候选池是用来选点的临时点，不是同时参与每步训练的额外参数；其计算时间已包含在总用时中。

参考实验结果

2026-08-26 在 CPU 上使用固定随机种完成 1500 步 Burgers 对比。两组都运行完成， 保存值、自适应采样器 checkpoint、诊断文件和 SVG 均通过检查。

限制和失败记录

  • 只接入一种残差概率分布变体，没有同时比较论文中所有自适应采样法。

  • 候选池太大会增加每次重采样成本；太小则可能找不到真正的高残差区。

  • 仅一个问题和随机种子，不作统计优越声明。

  • 最后一次候选/入选残差摘要保存为 sampling_diagnostics.json；失败另存 failure.json 和 failure_notes.md。
