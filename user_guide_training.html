12 · 方法选择、组合与参数调整

一个方法由“家族 / 具体变体”两级确定。正式实验建议两个名称都明确填写，避免以后默认变体变化影响复现。完整可编辑字段见附录 A。

家族使用时要注意
baseline普通 PINN，单独使用，作为比较起点
modified_mlp改变网络结构；参数量、时间可能随之改变
adaptive_activation设置激活初始斜率；不是增加一条 PDE
fourier设置频率数量与尺度；高频表达增强并不保证误差下降
hard_boundary有结构限制；当前自定义页面要求一维且左右为相同 Dirichlet 值
adaptive_weights一个家族只能选一个权重变体；查看权重和各损失而非只看总值
adaptive_sampling候选点与重采样会增加额外计算；检查采样诊断
adam_lbfgs按阶段运行；一次外层步可能多次求值，时间不只由 steps 决定
time_window含时间问题逐步扩大时间区域；与自适应采样占用同一采样位置
transfer必须有兼容 checkpoint；只加载模型初始化，不是完整恢复旧训练
domain_decomposition当前针对一维两材料界面，不是任意二维区域自动切分

12.1 可用组合示例

import openpinn as op

result = op.solve(
    "poisson",
    methods=[
        op.method("fourier", "random_fourier", num_frequencies=8),
        op.method("adaptive_weights", "relobralo", temperature=0.1),
    ],
    steps=5,
    model={"hidden_layers": [8, 8]},
    sampling={"interior": 16, "boundary": 8},
    output_root="runs/manual_composition",
)
print(result.output_dir)

不要在同一次调用中同时给 methods=[...] 和单方法 method/variant/method_options。常见被拒绝的组合包括：基线与改进方法、同一家族两个变体、时间窗与自适应采样、两个占用网络结构的改进。

12.2 修改参数的顺序

  1. 先固定问题、单位、边界和参考数据。
  2. 先跑 baseline 并保存结果。
  3. 每轮只变动一项，保存新代码及完整输出。
  4. 同时检查误差、时间、参数量和随机种子，不仅比较 loss 最后一行。
  5. 高权重、高频率、高采样分辨率都不等于“越高越好”。

13 · 双隧道二维模型专用操作

13.1 默认几何与物理单位

默认区域宽高各 40 m，两个半径 4 m 的隧道，圆心 (10,20) m 与 (30,20) m，分析 0–40 年。外壁与洞壁均为零超孔压，初始内部超孔压 p₀。默认 p₀=20 kPa、Cₓ=0.30 m²/年、Cᵧ=0.60 m²/年是可修改设置，不要当作任何特定工程必然正确的材料值。

13.2 运行并修改物理参数

import openpinn as op

result = op.solve(
    "tunnel_model1",
    method="baseline",
    steps=5,
    problem_options={"parameters": {
        "initial_pressure_kpa": 20.0,
        "consolidation_x_m2_per_year": 0.30,
        "consolidation_y_m2_per_year": 0.60,
    }},
    model={"hidden_layers": [8, 8]},
    output_root="runs/manual_tunnel",
)
print(result.output_dir)

这是运行检查代码。正式计算再调整预算。修改几何、时间或物理参数时，应同时修改用于对比的 COMSOL 模型和参考数据的单位换算。

13.3 哪些量是无量纲

模型输入采用 X=x/B、Y=y/H、τ=t/T，输出 U=p/p₀。默认时：米与年转换到模型坐标分别乘 1/40；模型输出还原 kPa 乘 20。predictions.npz 的基础 prediction 不是直接的 kPa。

13.4 打开哪些图

  • result.svg：物理坐标和孔压 kPa 的时间切片，共用色标。
  • diagnostics.svg：末时刻残差分布、孔压剖面、平均孔压消散。
  • loss.svg：优化过程，不是物理孔压。

默认原始空间评估网格为 61×61，默认时间切片为 0、20、40 年。显示层插值使云图更光滑，不会增加训练精度，也不会修改原始预测或指标。无需在通用配置器寻找“双隧道评估网格”按钮。

没有独立参考场时，先看 PDE 残差、边界/初值 RMSE、平均孔压消散和超出 [0,p₀] 的比例；软件不会凭空给出全场解的 L2/R²。要比较真实解误差，按下一章提供同一问题、同一单位、同一时刻的参考表。

15 · Python、YAML 与命令行的日常用法

15.1 Python 通用参数

参数填写示例 / 用途
steps / seed训练步数与随机种子
device / dtype默认 cpu / float32；可用设备取决于本地 PyTorch 环境
model{"hidden_layers": [64,64,64]}
sampling{"interior":128,"boundary":32,"initial":32}
training{"log_every":100}；不要把打印间隔误作采样间隔
problem_options修改内置问题域或物理参数
output_root结果父目录；自动生成本次运行子目录
output_dir显式指定本次目录；必须不存在或为空
plotFalse 可不生成标准结果图；不等于不保存预测/指标

15.2 紧凑 YAML

保存为 my_experiment.yaml：

schema_version: 2
problem:
  name: poisson
method:
  name: fourier
  variant: random_fourier
  options:
    num_frequencies: 16
    scale: 1.0
experiment:
  seed: 0
  device: cpu
training:
  steps: 1000
  log_every: 100
output:
  root: runs
python -m openpinn run --config my_experiment.yaml --steps 5
python -m openpinn show-config --problem poisson --method fourier --variant random_fourier --steps 5
python -m openpinn list-methods --family adaptive_sampling
紧凑 YAML 使用 schema_version: 2；结果目录中保存的展开配置是 schema_version: 1，不可直接交给 solve_config 当紧凑 YAML 重跑。当前紧凑 YAML/CLI 主要支持单方法；多方法组合使用 Python 的 methods=[...]。使用 --config 时，CLI 只将 --steps 与 --output-dir 作为额外覆盖传给该路径，种子等请改 YAML，不要以为所有命令行选项都会覆盖。

15.3 单方法参数的命令行写法

python -m openpinn run --problem poisson --method fourier --variant random_fourier --steps 5 --method-option num_frequencies=8 --method-option scale=1.0

重复 --method-option 增加参数。布尔/列表等优先使用 JSON 值格式，复杂组合更建议保存为 Python 文件。

组合优化器 / Adam 后接 L-BFGS

adam_lbfgs / adam_then_lbfgs

参数类型 / 默认值限制用途及调整影响
adam_lr
Adam 学习率		number
0.001		≥ 1e-12第一阶段 Adam 优化器的学习率。
调大前期下降可能更快但更易震荡或发散；调小更稳，但需要更多 Adam 步。
lbfgs_lr
L-BFGS 学习率		number
1.0		≥ 1e-12第二阶段 L-BFGS 优化器的学习率。
调大单次更新更激进，可能降低更快也可能不稳；调小更保守，收尾速度可能变慢。
lbfgs_fraction
L-BFGS 步数比例		number
0.02		≥ 1e-12；≤ 0.999999总外层训练步数中分给 L-BFGS 的比例。
调大给二阶收尾更多外层步、通常更耗时；调小把预算更多留给 Adam，可能收尾不足。
lbfgs_max_steps
L-BFGS 最大外层步数		integer
20		≥ 1限制 L-BFGS 使用的外层训练步数。

lbfgs_max_iter
每步最大内部迭代		integer
10		≥ 1每个 L-BFGS 外层步允许的最大内部迭代次数。
调大每个外层步可能更充分，但时间和显存成本上升；调小更快，单步优化可能不充分。
history_size
历史向量数量		integer
50		≥ 1L-BFGS 保存的历史校正向量数量。

线搜索		choice
'strong_wolfe'		可选 ['strong_wolfe']L-BFGS 使用的线搜索策略。

resample_every
移动间隔		integer
50		≥ 1每隔多少个外层训练步移动一次配点。
调小会更频繁更新且更耗时；调大更省算力，但点对当前解变化的响应更慢。

参数类型 / 默认值限制用途及调整影响

调大能更好估计重要性分布，但增加每次评估成本；调小更快但概率估计噪声更大。

数值稳定量		number
1e-12		≥ 0.0计算抽样概率和逆概率权重时使用的极小正数。
调大可压低极端逆概率权重、提高稳定性，但会削弱重要性差异；过小可能产生很大的修正权重。

调小能更快跟随损失分布但增加成本和方差；调大更省算力，但采样概率可能过时。

0.01		≥ 1e-12损失权重梯度上升时使用的学习率。
调大让权重反应更快，但可能振荡或迅速顶到上限；调小更稳定，但难以在有限步数内明显调整。

最大权重		number

调大允许更强地关注困难项，但可能造成梯度爆炸；调小更稳，却可能限制自适应能力。

自适应权重 / 不确定性损失权重

参数类型 / 默认值限制用途及调整影响

10.0		无额外数值范围；仍须满足类型与运行校验对数方差参数的上界。
设得更大允许把高不确定项降得更低，也可能近似忽略该项；降低上界可避免过度降权。

自适应权重 / ReLoBRaLo 相对损失平衡

adaptive_weights / relobralo

参数类型 / 默认值限制用途及调整影响
alpha
历史平滑系数		number
0.999		≥ 0.0；≤ 1.0当前权重与历史权重之间的指数平滑系数。
接近 1 时权重更平滑、记忆更长但响应慢；减小时响应更快，也更容易抖动。
temperature
温度		number
0.1		≥ 1e-12控制相对损失 softmax 分布的尖锐程度。

expected_lookback

0.999		≥ 0.0；≤ 1.0使用上一步损失而非初始损失的期望概率。

seed
方法随机种子		integer
0		≥ 0随机回看过程的随机种子。
改变它会改变随机回看序列，不存在越大越好；公平比较时应固定或采用多随机种子。
