14 · 使用 COMSOL / CSV 独立参考场

14.1 准备数据

参考表是“坐标 + 场值”，不是几何文件。可用带表头 CSV、制表符表，或带 % 注释、空白分隔数值的 COMSOL Spreadsheet 风格表。支持按列名或从 1 开始的 #1、#2 选列。多时间导出成多个压力列时，每次明确选定一列和对应时间，不会自动识别所有宽表时间列。

x,y,t,p
5,5,20,12.4
20,20,20,15.1
35,35,20,12.2

这里只是格式示意，数值不是可信双隧道参考解，请使用自己的求解数据。

14.2 在页面逐项填写

  1. 启用“训练后对比独立参考场”。
  2. 选择文件用于预览列名。
  3. 把实际文件放进项目，例如 examples/references/my_field.csv，填写运行时路径。
  4. 按模型输入顺序填坐标列，例如 x,y,t。不要填成 y,x,t。
  5. 选择场值列，例如 p；多输出模型选择分量编号，u 的第一列为 0。
  6. 填写坐标、参考值和预测值各自的换算系数。
  7. 复制代码运行，训练结束后自动执行参考评价。
默认双隧道，导出 m/年/kPa填写值
坐标列x,y,t
坐标换算系数0.025,0.025,0.025
参考场值换算系数1
模型预测换算系数20

如果参考压力以 Pa 导出而想报告 kPa，参考值系数填 0.001。若只导出 t=20 年一张切片且文件只有 x/y 列，坐标列填 x,y，固定时间填 20，但坐标系数仍应有 x/y/t 三项。

14.3 运行后产物

  • reference_metrics.json：相对 L2、RMSE、MAE、最大绝对误差、R²、样本数、文件哈希和换算设置。
  • reference_predictions.csv：逐点参考、预测、绝对误差。
  • reference_comparison.svg：比较图。
  • metrics.json 追加 external_reference_* 指标。
参考表只用于训练后评价，不参与损失训练。模型直接在参考坐标预测，没有先把参考场插值到另一张网格。指标按不同样本点等权计算，不能自动解释成不规则网格上的面积/体积积分误差。重复坐标的相同值会去重，冲突值会被拒绝；传入问题对象时域外点会报错，而非默默删掉。

16 · 结果文件逐项使用说明

文件怎样使用注意
config.yaml核对实际问题、网络、方法、训练和输出设置是展开配置，不是网页表单的原样备份
status.json查看 completed/failed、finite_outputs、accuracy_claimcompleted 不等于达到工程精度；accuracy_claim 默认 false
metrics.json查看定量评价，比较相同条件运行先区分解误差、PDE 残差与训练损失
history.csv用表格软件或 Python 查看训练过程含 step、total 和具名损失；日志少不意味着历史没保存
predictions.npz读取原始坐标、预测、残差及可用参考图片显示插值不会写回这些数组
compute_ledger.json查看时间、设备、参数量、closure 次数等elapsed_seconds 主要是 fit 计时，不是安装/全部后处理总耗时
checkpoint.pt兼容结构的模型迁移或底层断点恢复不是双击即可运行的程序；只加载可信文件
result.svg / loss.svg浏览器或矢量图查看器打开自定义问题不会自动获得每种物理量的专用二维图
diagnostics.svg双隧道物理诊断不是所有问题都会生成
sampling_diagnostics.json / optimizer_diagnostics.json分析采用相应方法后的运行细节组件返回诊断时才生成
failure_notes.md查看失败或限制说明运行完成后的通用说明不是独立质量认证
manifest.json文件大小与 SHA-256，方便交付核对手工编辑输出后哈希将不再一致

17 · 怎样判断指标，而不是只看图

指标读取方式解释边界
相对 L2‖预测−参考‖₂ / ‖参考‖₂，越小越好无量纲；参考接近全零时分母保护会使数值难解释；不是绝对 L2
RMSE误差平方均值开根号，越小越好与场值同单位，必须先对齐物理单位
MAE绝对误差平均值对局部极端误差敏感性低于最大误差
最大绝对误差所有评估点中最大的绝对差受评估点覆盖和离群点影响
R²1−残差平方和/参考离均差平方和可以为负；参考为常数时当前实现用有限值约定，不适合照常解释
PDE residual RMSE控制方程残差相对 0 的 RMSE不是与参考解比较的 RMSE
boundary / initial RMSE边界或初值条件误差不能替代全域解的误差
final_total_loss训练目标的最终记录不同权重/幂变换方法的总损失不能直接当成同一精度尺度

所谓“absolute 差值很大”，首先检查量纲、坐标顺序、时间切片、边界设定和参考场是否属于同一问题。光滑云图、很小 PDE 残差和较低训练损失各自只能说明一部分情况；它们不等价于正确工程预测。

内置参考指标常用键为 relative_l2_error、r2_score；外部参考文件中常用 relative_l2、r2。命名有差别，比较时确认取的是同一类指标。

18 · 迁移、重复实验与结果交接

18.1 使用已有模型开始新训练

import openpinn as op

result = op.solve(
    "poisson",
    method="transfer",
    variant="checkpoint_transfer",
    method_options={"checkpoint": "runs/源运行/checkpoint.pt"},
    steps=1000,
    output_root="runs/transfer_runs",
)

源模型的输入/输出维度和网络结构必须匹配。若源运行使用了 [8,8] 网络，而本次未指定相同 model，就不能期望默认 [64,64,64] 网络成功加载。

迁移只使用模型权重作初始化。完整断点恢复还包括优化器、采样器、随机状态、历史与步数；这是底层 Trainer 的独立操作，不是网页上选择 transfer 的含义。

18.2 正式比较

  1. 给每个实验保存完整脚本与参考数据来源。
  2. 固定问题、训练预算、网络/采样条件与评估坐标；只更改计划比较的方法。
  3. 用多个明确记录的随机种子重复，报告均值、离散程度及失败运行。
  4. 把结果目录整体交接，不要只发送一张 result.svg。

18.3 交付清单

至少包含：运行脚本、依赖环境信息、实际展开配置、metrics、原始 predictions、history、compute ledger、checkpoint（需要复用时）、manifest、参考数据及其单位说明。涉及外部数据共享时先确认可分享范围。说明运行机器、时间与限制，不把短跑结果写成精度验证完成。
