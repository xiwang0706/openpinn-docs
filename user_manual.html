01 · 阅读方法与使用范围

核心使用流程：自定义几何 → 控制方程 → 边界条件 → 生成训练代码 → 本地运行与验证。

不必把自己的问题改成某个内置案例。先用第 03 章确认环境，再按下列路线建立自己的计算模型。

  1. 设置计算区域，或导入图片/坐标、导入 DXF。
  2. 选择模板、公式与物理参数或按项组合，确认系数与符号。
  3. 逐边设置条件及初值，区分外边界和孔洞。
  4. 核对并生成训练代码，保存脚本后独立运行。
  5. 检查物理条件及参考误差，不以预览图代替验证。

可直接跟做：一维不同端点条件 · 二维不规则区域 · 两个圆孔区域。

这份说明书只回答“如何操作 OpenPINN”。第一次使用请依次阅读安装、第一次运行、配置器操作和结果查看；需要导入图片、DXF 或 COMSOL 参考表时，再进入对应章节。所有命令除另有注明外都在项目根目录执行，即包含 pyproject.toml 的文件夹。

02 · 安装、环境检查与打开页面

2.1 先分清阅读、构建和训练

“安装”指配置 OpenPINN 的 Python 计算环境，不是安装浏览器插件。下载源码后，docs/manuals/public/user_manual.html 和 developer_manual.html 已经存在，可用浏览器离线阅读；完整配置器网站的 docs/_build/html/ 尚不存在，必须先按下方步骤生成。

需要 Python 3.10 或以上（本次 macOS 走查为 3.13.9，新手可选常规 3.13.x 安装程序）与 Node.js 24.x、版本不低于 24.15.0。下载对应系统的安装程序，而不是 Source release。Windows 安装参见 Python 官方说明。安装后重新打开终端，确认版本检查命令能输出版本号。没有 GPU 也能在 CPU 上完成首次短运行。

先完整解压项目；同时包含 README.md、pyproject.toml、src/ 和 docs/ 的文件夹是项目根目录。在 macOS 终端输入 cd 和一个空格，把项目文件夹从 Finder 拖入后按回车；执行 ls pyproject.toml 应显示文件名。Windows 在该文件夹的地址栏输入 powershell 并按回车，执行 Test-Path .\pyproject.toml 应输出 True。Linux 在该文件夹打开终端。不要照抄“你的路径”这样的占位文字。

2.2 macOS / Linux 安装

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[test,docs]"
python -c "import openpinn; print(openpinn.__version__); print(openpinn.__file__)"

安装检查应显示 0.2.0。每次新开终端，先回到项目根目录，再执行 source .venv/bin/activate。已有可靠 Conda/PyTorch 环境时可继续使用原环境，不要盲目替换 CUDA/PyTorch。命令逐行执行，遇到错误先停止，不要继续下一步。

03 · 第一次运行：从网页下载到看到结果

3.1 先从网页下载一个 Poisson 示例

  1. 打开配置生成器，控制方程选择 Poisson（一维） · poisson；训练步数填 5，终端输出间隔填 1，随机种子填 0，结果文件夹填 runs。
  2. 只勾选普通 PINN（baseline），其余方法不选；其他参数保持默认。不勾选“训练后对比独立参考场”。
  3. 点击“下载 .py”，得到 poisson.py。在电脑的“下载”文件夹中明确重命名为 first_poisson_run.py，再移动到项目 examples/。仓库自带 examples/poisson.py，不要覆盖它。重复下载或再次运行时也不要覆盖自己的旧脚本，若另取名字需同步修改命令。
  4. 回到项目根目录，执行对应系统的命令；不要双击 .py，不要在浏览器地址栏执行命令。

macOS/Linux（已激活环境）：

python examples/first_poisson_run.py

Windows PowerShell：

.\.venv\Scripts\python.exe examples\first_poisson_run.py

终端应出现 step=1 等日志，结束后打印“结果目录：……”。进入这个目录，用浏览器打开 result.svg 和 loss.svg，用文本编辑器查看 status.json，检查 status 为 completed、finite_outputs 为 true。仅 5 步不能保证图像拟合或物理精度；这里只验证完整流程。

3.2 可选：手写一个小预算检查脚本

已经跑通网页下载路线可跳过本节。愿意手写代码时，在项目根目录新建 my_first_run.py，保存以下完整代码：

import openpinn as op

result = op.solve(
    "poisson",
    method="baseline",
    variant="plain_pinn",
    steps=5,
    seed=0,
    model={"hidden_layers": [8, 8]},
    sampling={"interior": 16, "boundary": 8},
    training={"log_every": 1},
    output_root="runs/manual_first_run",
)
print("结果目录：", result.output_dir)
print("指标：", result.metrics)

macOS/Linux（已激活环境）：

python my_first_run.py

Windows PowerShell：

.\.venv\Scripts\python.exe my_first_run.py
  1. 终端出现 step=1 total=... 等输出。
  2. 结束时打印独立结果目录。
  3. 打开该目录的 status.json，检查状态及 finite_outputs。
  4. 打开 result.svg 和 loss.svg，再检查 metrics.json。
5 步及小网络仅检查程序能否完成，不用于判断模型精度。正式计算时调整回合适的网络、采样点与步数，并用独立参考数据或物理约束检查结果。

3.3 可选：命令行方式

python -m openpinn run --problem poisson --method baseline --variant plain_pinn --steps 5

终端最后会打印 JSON 概要。结果目录一般在当前工作目录的 runs 下。不要反复把同一个非空目录作为 --output-dir；软件会拒绝覆盖。

3.4 停止运行

在终端按 Ctrl+C 可中断当前运行。不要假定中断时一定已有最新检查点：标准实验通常在完整训练和评估后写出最终 checkpoint。重新运行默认会创建新目录。

04 · 配置生成器完整操作流程

  1. 选择控制方程。内置问题直接选择；自己的问题选择“新控制方程（可视化一维/二维）”。
  2. 设置通用参数。填训练步数、终端输出间隔、随机种子、结果文件夹。
  3. 如有需要，开启独立参考场对比。填写表格路径、列名、换算系数；不了解时先关闭，先跑通。
  4. 自定义问题设置区域与条件。确认几何、维度、时间区间、每条边的条件及 PDE 公式。
  5. 选择方法及变体。勾选一个或多个兼容方法，修改右侧专用参数；基线方法不能与改进方法一起勾选。
  6. 检查提示。有冲突、空值或非法几何时先处理错误，不要复制之前生成的旧代码。
  7. 复制代码。如果复制代码，保存到 examples/my_openpinn_run.py；如果下载脚本，先明确重命名为 my_openpinn_run.py 才能使用下一步的示例命令。
  8. 执行。在项目根目录运行 python examples/my_openpinn_run.py；Windows 未激活环境时，命令开头改用 .\.venv\Scripts\python.exe。
  9. 检查结果。根据打印的目录查看图、指标、配置和状态。
页面字段如何填写容易混淆的地方
训练步数正整数；先少量测试再增加表示外层优化步，不等于 L-BFGS 内部迭代次数
终端输出间隔正整数，例如 100只影响日志打印，不改变重采样频率
随机种子非负整数，例如 0不是“越大越好”；正式比较应记录并固定
结果文件夹例如 runs生成脚本会依照其 PROJECT_ROOT 规则解析相对路径
方法专用参数按字段类型填数值、布尔值、列表或映射“权重学习率”等不是网络 Adam 学习率

4.1 查看与保存完整代码

完整 Python 代码区独占整行，高度随窗口调整。点击“放大查看”可扩大阅读区域，按 Esc 或“关闭放大”返回。代码保留原始缩进、不自动换行，长行请横向滚动。可使用“复制代码”，也可直接点击“下载 .py”；下载后请把脚本移入项目 examples/ 目录，在项目根目录运行 python examples/实际文件名.py。下载按问题名命名（例如 poisson.py 或 my_new_equation.py），不要把 实际文件名 当成名称照抄。Windows 未激活环境时用 .\.venv\Scripts\python.exe 替换命令开头的 python。参数无效时复制和下载均禁用，修正后重新保存。

页面不是在线计算服务器；复制或下载代码都不会立即提交训练。几何文件在浏览器中解析，轮廓会嵌入生成代码；参考数据表则需要你另行放到运行机器可读取的位置。

配置器脚本按 examples/ 内的保存位置组织项目路径。若把文件挪到任意目录，先检查代码开头的 PROJECT_ROOT 与 OUTPUT_ROOT，不要假定相对路径仍相同。保存代码才是保留本次配置的可靠方式，不要依赖浏览器刷新后自动恢复输入。

06 · 自定义建模主流程：几何、PDE、边界与训练代码

本章把分散的设置连成一个可交付的操作流程。几何决定“在哪里求解”，控制方程决定“域内满足什么关系”，边界和初值决定“边上及起始时刻满足什么”；最后生成的 Python 脚本才是实际训练的输入。后续第 07–11 章提供各控件的详细说明。

6.1 先设置问题维度

  1. 填写便于区分结果的问题名称。
  2. 静态方程没有时间输入；含时间方程需要 t 下限与上限。
  3. 一维的输入为 x 或 (x,t)；二维为 (x,y) 或 (x,y,t)。时间放在最后一列。
  4. 每个上限必须严格大于对应下限；二维几何若导入文件，则以导入坐标和明确的换算为准。

6.2 常用模板

静态模板提供 Poisson 制造解、Helmholtz 制造解、非线性 Poisson 制造解；动态提供线性热方程、三次反应–扩散、Allen–Cahn、对流–扩散，一维动态还提供 Burgers。切换模板后核对展开的系数和公式，不要沿用上一个模板的物理解释。

静态模板的“制造解”误差评价有适用条件：当前生成逻辑要求使用矩形/一维区域、所有边界均为且等值的 Dirichlet，并处于静态模板模式。任意多边形、圆、椭圆、圆角矩形、样条或不满足上述条件时，不应期待自动附带解析参考解。

6.3 公式与物理参数，以及旧版按项组合

方程编辑模式 → 公式与物理参数（推荐）。

先设空间维度和静态/含时间，再选择兼容模板、核对未知场及单位。编辑区先显示导数按钮、公式框和公式预览，下方是当前参数。参数和公式经过安全语法与量纲校验后，直接进入生成的训练代码。内置参数定义不提供通用材料值，模板数值仅作演示。

例如输入二维孔压扩散方程 ∂u/∂t = cx·∂²u/∂x² + cy·∂²u/∂y²：

  1. 问题类型选“含时间方程”，空间维度选“二维”，再进入公式模式。
  2. 加载“二维各向异性固结（cx / cy）”模板带入方程和 cx、cy。场变量符号改为 u 后移出输入框，公式中的 p 会同步改名，得到下面的表达式；场单位按实际压力设置。
  3. 在“当前方程的参数”填写两个系数的实际数值与单位，如 m^2/s 或 m^2/year。已有模板参数不用重复从库中添加。
  4. 核对预览与生成代码，再设置计算区域、时间范围、初值和边界。统一初始孔压可选“常数初值”。
dt(u) = cx * dx(dx(u)) + cy * dy(dy(u))

cx、cy 是系数，不是压力的导数。点击 ∂u/∂t、∂²u/∂x²、∂²u/∂y² 按钮可在光标处插入导数，不必手动嵌套两次；选中表达式再点击，会对选中部分求导。按钮中的符号跟随场变量设置变化。一维时 y 导数不可用，静态时 t 导数不可用。模板默认用 p 表示孔压，采用等号形式 dt(p) = cx * dx(dx(p)) + cy * dy(dy(p))；两个系数为常数时，与散度形式等价。若系数依赖坐标，不能直接移出导数。场变量改名仅替换完整变量符号，不改写参数或函数名。

当前参数默认只显示名称、符号、数值、单位；公式中填写“符号”。每行的高级信息默认折叠，包含 id、说明和来源；id 只是参数包的唯一引用，不必写进方程。展开添加参数区域，才会看到常用参数库、自定义参数和材料组。新增自定义参数的 id 可以留空，编辑器按符号自动生成并避开已占用标识；公式符号仍须唯一。

需要保存或迁移时展开“导入与导出”：物理工程 JSON 保存公式、参数和单位，参数包用于分享定义与材料数值。两者都不包含几何、边界或训练设置。模板也不会自动切换主配置的维度/静动态或改写几何、边界、初值，请自行核对。新入口支持单场一维/二维，不代表完整 Biot 耦合。几何/场值使用选定单位，残差内部转为 SI；Neumann 仍为显示单位下的法向导数，并非自动换算的渗流通量。

原“自由组合”现标为“按项组合（兼容旧版）”。每一行是“带符号系数 × 一项”，所有行求和等于 0。例如 u_t − 0.1u_xx = 0 填两行：1 × u_t、−0.1 × u_xx。源项在等式右侧时，移到左侧再填其符号。

可选项操作含义范围
u、u²、u³未知量本身及非线性项一维/二维，静态/动态
u_x、u_xxx 一阶、二阶导数所有空间问题
u_y、u_yyy 一阶、二阶导数仅二维

点击“添加方程项”增加一行，点击“删除”移除对应项。相同项重复出现会累加，例如三个 1×u 等价于 3u。不要把示例正弦场当成任意自由组合的解。

旧版按项组合只提供固定项，不解析任意公式字符串；上面的新公式模式支持限定语法，但也不提供任意多场耦合编辑。旧版即使可选择 u_tt，页面也没有独立初始速度输入；真正的二阶时间问题通常需要额外初始条件，不能只填一个初值就认为问题完整。新公式模式拒绝二阶时间导数。这类需求应由熟悉问题定义的人补充生成脚本。

6.4 跟做案例 A：一维区域，两端条件不同

目标：在 0≤x≤1 上求 −u_xx=0，左端 u=0、右端 u=1。此例的解析解为 u=x，用于理解设置；自由组合模式不会因此自动生成参考误差。

  1. 在配置器选择“新控制方程（可视化一维/二维）”，问题名填写 custom_interval，问题类型选静态，空间维度选一维。
  2. x 下限填 0、上限填 1；方程编辑模式选“按项组合（兼容旧版）”。删掉不需要的行，只保留 −1 × u_xx。
  3. 左边界选 Dirichlet，目标值填 0；右边界选 Dirichlet，目标值填 1。此处纵向显示的是场值 u，不是第二个空间坐标。
  4. 先选择基线方法。不要选择当前只适用于左右等值 Dirichlet 的硬边界变体。
  5. 在生成代码内核对 X_MIN=0、X_MAX=1、LEFT_BOUNDARY_VALUE=0、RIGHT_BOUNDARY_VALUE=1，并核对残差只含负的 x 二阶导数。
  6. 按 6.7 节保存并短跑，确认没有运行错误后，再增加训练步数。若另行准备独立参考 CSV，可按第 14 章填写 x 与参考 u=x；少量步数不能保证预测已接近直线。

单参数联动检查：把右边界目标值改成 2，提交后确认右端显示值及 RIGHT_BOUNDARY_VALUE 都改变；左端仍为 0。复制新代码后训练的目标才变成 u=2x，已运行的旧脚本不会自动更新。

6.5 跟做案例 B：二维不规则区域，逐边设置条件

目标：导入一个无孔洞的三角形，在域内求 −u_xx−u_yy−1=0，所有边取零 Dirichlet。以下是用于熟悉逐边设置的无量纲示例，不对应特定工程材料。

  1. 新建静态、二维、“按项组合（兼容旧版）”问题 custom_triangle。选择“导入多边形文件（识别图片）”，按导入面板的“文件格式示例”制作坐标文件，三个顶点依次为 (0,0)、(2,0)、(0,1)，不设置孔洞。
  2. 导入后核对三条边及图内编号：1→2、2→3、3→1。应只有一个外环，不应出现额外孔洞。
  3. 按项组合仅保留三项：−1 × u_xx、−1 × u_yy、−1 × 常数 1。核对显示公式等价于 −Δu=1。
  4. 逐条边选择 Dirichlet、目标值 0。每个控件只代表对应编号的边，不是整张图统一设置。
  5. 在图中移动一个顶点或提交新的边长，检查编号和边长，再检查生成代码中的 POLYGON_VERTICES。无效、自交的轮廓不能作为最终几何。
  6. 若要演示混合边界，可把其中一边改成 Neumann、q=0，其余两边保留 Dirichlet 0；核对生成代码中该边使用法向导数条件。不要只改标签而忽略实际类型。
  7. 选择基线、生成并保存代码，按 6.7 节运行。此例没有自动解析解，不应把“没有 L2/R²”误认为没有执行。

6.6 跟做案例 C：矩形外轮廓与两个圆孔

目标：导入带两个圆孔的二维 DXF，编辑两个孔洞并设置各自条件。为便于自查，可准备外框 [0,40]×[0,40]、圆心 (10,20) 与 (30,20)、半径均为 4 的图形，导出后按实际图纸单位设置换算。

  1. 选择二维的 CAD/COMSOL 几何导入入口，导入 DXF。确认状态为一个外轮廓、两个孔洞；不要用 .mph 重命名为 .dxf。
  2. 查看图中“孔洞 1”“孔洞 2”的实际位置，再在轮廓选择器选对应孔洞。编号以导入结果为准，不预设左孔一定是 1。
  3. 若已识别为圆形，输入圆心坐标、半径或直径。把选中孔的直径从 8 改成 10，提交后确认 D=10、半径=5、另一孔未改变；检查孔洞仍在外框内且彼此不相交。
  4. 核对生成代码中对应 HOLE_N_CENTER_X、HOLE_N_CENTER_Y 和 HOLE_N_RADIUS；N 使用图上的编号。若列表仍显示很多短边，则该孔未被识别为圆形，先检查 DXF 轮廓和缩放，不能按“整圆孔”流程假设成功。
  5. 先做静态演示：域内设置 −u_xx−u_yy−1=0；外框各边设置 Neumann q=0，两个孔分别设置 Dirichlet c=0。孔壁的计算域外法线指向孔内。
  6. 每个已识别的圆孔应只设置一组边界条件；外框仍逐边设置。生成代码中用整环选择器覆盖该孔，不需要给几十段短边分别填同一个值。
  7. 选择基线，保存并运行。这个静态演示不是内置双隧道固结物理模型；要研究孔压随时间变化，还需自行确认物理系数、单位、含时间 PDE 和初值，或使用第 13 章的专用模型。
外框为四顶点轴对齐矩形、全部孔洞均已识别为圆时，生成代码使用 op.RectangleWithCircularHoles，按圆心和半径精确描述训练边界。请在导入提示中确认“训练几何：解析矩形＋圆孔”。其他轮廓仍用 op.Polygon，页面会说明分段近似。图片/DXF 导入只带入几何，不会同时导入 COMSOL 的材料、PDE、边界条件或解场。

7.1 椭圆 a、b 的使用

不旋转时，几何满足 ((x−cx)/a)² + ((y−cy)/b)² = 1。例如 a=2、b=1，横向总宽为 4、纵向总高为 2。旋转改变方向，不改变两个半轴长度。a 只是局部 x 半轴，不强制必须大于 b。

7.2 曲线张力不是曲率

张力为 0 时更圆滑，接近 1 时更贴近控制折线。张力不等于数学曲率 κ，也没有固定物理单位；不能把张力 0.2 解释为曲率 0.2 m⁻¹。需要严格圆弧时优先直接使用圆/圆角几何，需要沿轮廓的复杂形状时使用闭合曲线。

7.3 原点与坐标

查看坐标范围、轴名和原点标识；如果 (0,0) 本来在当前计算范围之外，不要为了显示原点而误改几何。改变 Dirichlet 值改变的是边界上的场值 u，不会把二维几何的 y 坐标整体平移。

08 · 从图片或坐标文件导入区域

8.1 图片操作步骤

  1. 选择“导入多边形文件（识别图片）”，选择 PNG/JPG。
  2. 尽量使用裁剪干净的填充色块图：外背景与实体区域可区分，孔洞使用背景色；避免尺寸标注、文字、阴影或其他图形接触轮廓。
  3. 先使用自动前景、自动二值化、1024 px 识别分辨率。
  4. 填写用于像素映射的 x/y 物理坐标范围。它不是自动测得的工程尺寸，导入后必须核对宽高比例和实际边长。
  5. 点击“按当前设置重新识别”，查看外轮廓、孔洞数量以及提示。
  6. 若细孔或细边丢失，提高分辨率或降低拐角简化量；若像素阶梯产生很多点，适当提高简化量。
  7. 识别完成后编辑轮廓、设置边界并复制代码。

8.2 坐标文件操作

同一入口也支持 CSV、JSON 和 GeoJSON Polygon。一个文件描述一条外轮廓及可选孔洞；不支持 MultiPolygon。每个环至少三个不重复有效顶点；不得自相交，孔洞必须在外轮廓内，不得互相重叠或穿出边界。

ring,x,y
outer,0,0
outer,4,0
outer,2,3
{
  "outer": [[0,0], [4,0], [4,4], [0,4]],
  "holes": [[[1,1], [1,2], [2,2], [2,1]]]
}

GeoJSON 使用 Polygon 的外环、内环结构；其标准闭环会重复首尾坐标。导入后会进行标准化。网页单文件限制 5 MB，每个边界环最多 5,000 个顶点；超大工程图应先提取真正的计算区域。

五角星有 5 个外尖角，但完整轮廓通常还有 5 个凹角，共 10 个关键顶点。不要为了只剩 5 个点而丢掉凹角；应去掉的是像素阶梯碎点。

10 · 编辑顶点、边长、圆孔尺寸及编号

10.1 先选对正在编辑的边界环

在醒目的“选择要编辑的外轮廓 / 孔洞”下拉框中选择对象。图内的“孔洞 1”“孔洞 2”与这个下拉框、边界条件行保持一致。编号是导入后的顺序，不保证左边一定是孔洞 1；重新导入另一文件后必须按图核对。

10.2 普通多边形

  1. 选择外轮廓或某个非圆孔。
  2. 在图中拖动顶点，或者在表格中输入该顶点 x/y 坐标。
  3. “到下一顶点的边长”对应 i→i+1，最后一点连回第一点；修改会移动相关顶点，也可能改变邻接边。
  4. 修改内角、插入或删除顶点后，重新核对编号和对应边界条件。它不是能同时锁定所有长度、角度的 CAD 约束求解器。
  5. 若提示自相交、孔洞越界或重叠，不要忽略；先把轮廓恢复到有效状态。

10.3 已识别的 DXF 圆孔

  1. 选择“孔洞 N（圆形）”。
  2. 输入圆心 x、圆心 y、半径 r 或直径 D；D=2r。
  3. 完成输入并提交字段（回车或移出输入框）后核对预览。该编辑器的部分字段按 change 事件提交，不保证打字每个字符都立即生效。
  4. 图内显示孔洞编号和 D；当前圆孔以蓝色虚线突出。
  5. 检查生成代码中的 HOLE_N_CENTER_X、HOLE_N_CENTER_Y、HOLE_N_RADIUS 已更新。
圆孔识别不是把所有看起来像圆的对象无条件改成圆。对椭圆或粗糙轮廓不要强行使用圆的解释。只有四顶点轴对齐矩形＋全部圆孔走解析训练路径；其他情况保留多边形近似。提示中的圆孔弦高 r*(1-cos(π/N)) 只衡量等角点列相对拟合圆的离散误差，不衡量拟合圆相对原图的识别误差。拖动外框变成非矩形后，请重新检查“训练几何”提示与生成代码。

10.4 整体变换与恢复

可以填写旋转角、X/Y 缩放、X/Y 平移后点击“应用整体变换”。操作会影响整个导入区域，先确认所有孔洞都应一起移动。非等比例缩放会改变圆的形状，之后应重新检查是否仍被当作圆孔。点击“恢复刚导入的轮廓”前，先保存需要保留的生成代码；恢复会撤销本次几何调整。

10.5 修改后的核对顺序

依次核对：图中形状 → 顶点/孔洞编号 → 边界条件对象 → 代码中的坐标与条件 → 5 步运行输出。对一份已经复制到编辑器里的脚本，后来修改网页不会自动回写；必须重新复制保存。

11 · 边界和初值怎么填写

类型页面输入具体含义例子
Dirichlet目标值 c规定边界上 u=c排水壁超孔压 0；固定温度 20
Neumann目标值 q规定外法向导数 ∂u/∂n=q零法向梯度 q=0
Robin目标值 c、α、β规定 αu+β∂u/∂n=c同一条件中同时出现值与导数

Neumann 输入当前指法向导数，不是自动乘好材料系数的物理通量。若你的通量定义为 −k∂u/∂n，应先换算符号和系数。外法线指向计算域外：左边界指向负 x，右边界指向正 x；孔洞边界的计算域外法线指向孔内。

  • 一维：左右分别设置，可以不同。
  • 矩形：上下左右分别设置，可以不同。
  • 普通多边形：逐条 i→j 设置；孔洞的边也按其局部编号设置。
  • 直接圆形、椭圆、圆角矩形、平滑闭合样条：当前页面按连续整圈设置一组条件。
  • 识别出的 DXF 圆孔：每个圆孔一组，不需要逐个短边重复输入。

11.1 一维 Dirichlet 与 y 轴

若显示的是 u(x) 曲线，改变端点值会改变示意曲线的端点高度和显示值域；这个纵轴代表 u。若显示二维区域，y 轴是空间坐标，改变 u 的边界值只影响场值表达，不能改变区域的 y 范围。

11.2 初值与兼容性

含时间问题可选择正弦场、高斯场或零初值。检查 t=初始时刻的边界与初值是否符合你的问题。例如初值在边界为 1、边界要求始终 0，会出现初边值交角处的不连续；它可能是模型设定本身，不是通过画图平滑就能消除的错误。

不要给同一边重复设定彼此冲突的条件，也不要将 Robin 的 α、β 同时设为 0。纯 Neumann 问题可能需要额外参考值或守恒兼容条件；界面允许输入并不保证数学问题唯一可解。当前没有页面周期边界选项。

12 · 方法选择、组合与参数调整

一个方法由“家族 / 具体变体”两级确定。正式实验建议两个名称都明确填写，避免以后默认变体变化影响复现。完整可编辑字段见附录 A。

家族使用时要注意
baseline普通 PINN，单独使用，作为比较起点
modified_mlp改变网络结构；参数量、时间可能随之改变
adaptive_activation设置激活初始斜率；不是增加一条 PDE
fourier设置频率数量与尺度；高频表达增强并不保证误差下降
hard_boundary有结构限制；当前自定义页面要求一维且左右为相同 Dirichlet 值
adaptive_weights一个家族只能选一个权重变体；查看权重和各损失而非只看总值
adaptive_sampling候选点与重采样会增加额外计算；检查采样诊断
adam_lbfgs按阶段运行；一次外层步可能多次求值，时间不只由 steps 决定
time_window含时间问题逐步扩大时间区域；与自适应采样占用同一采样位置
transfer必须有兼容 checkpoint；只加载模型初始化，不是完整恢复旧训练
domain_decomposition当前针对一维两材料界面，不是任意二维区域自动切分

12.1 可用组合示例

import openpinn as op

result = op.solve(
    "poisson",
    methods=[
        op.method("fourier", "random_fourier", num_frequencies=8),
        op.method("adaptive_weights", "relobralo", temperature=0.1),
    ],
    steps=5,
    model={"hidden_layers": [8, 8]},
    sampling={"interior": 16, "boundary": 8},
    output_root="runs/manual_composition",
)
print(result.output_dir)

不要在同一次调用中同时给 methods=[...] 和单方法 method/variant/method_options。常见被拒绝的组合包括：基线与改进方法、同一家族两个变体、时间窗与自适应采样、两个占用网络结构的改进。

12.2 修改参数的顺序

  1. 先固定问题、单位、边界和参考数据。
  2. 先跑 baseline 并保存结果。
  3. 每轮只变动一项，保存新代码及完整输出。
  4. 同时检查误差、时间、参数量和随机种子，不仅比较 loss 最后一行。
  5. 高权重、高频率、高采样分辨率都不等于“越高越好”。

17 · 怎样判断指标，而不是只看图

指标读取方式解释边界
相对 L2‖预测−参考‖₂ / ‖参考‖₂，越小越好无量纲；参考接近全零时分母保护会使数值难解释；不是绝对 L2
RMSE误差平方均值开根号，越小越好与场值同单位，必须先对齐物理单位
MAE绝对误差平均值对局部极端误差敏感性低于最大误差
最大绝对误差所有评估点中最大的绝对差受评估点覆盖和离群点影响
R²1−残差平方和/参考离均差平方和可以为负；参考为常数时当前实现用有限值约定，不适合照常解释
PDE residual RMSE控制方程残差相对 0 的 RMSE不是与参考解比较的 RMSE
boundary / initial RMSE边界或初值条件误差不能替代全域解的误差
final_total_loss训练目标的最终记录不同权重/幂变换方法的总损失不能直接当成同一精度尺度

所谓“absolute 差值很大”，首先检查量纲、坐标顺序、时间切片、边界设定和参考场是否属于同一问题。光滑云图、很小 PDE 残差和较低训练损失各自只能说明一部分情况；它们不等价于正确工程预测。

内置参考指标常用键为 relative_l2_error、r2_score；外部参考文件中常用 relative_l2、r2。命名有差别，比较时确认取的是同一类指标。
