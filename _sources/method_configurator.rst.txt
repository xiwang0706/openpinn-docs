配置生成器
============

在下方配置问题、方法与参数，生成完整 Python 训练脚本。第一次使用可顺着流程图操作；
点击图中方框会在本页定位到对应设置或操作说明。已经熟悉流程，可直接点击“开始配置”。

.. openpinn-configurator-guide::

.. raw:: html

   <details class="configurator-usage-details"><summary>详细说明：导入格式、代码操作与功能限制（按需展开）</summary>

选择控制方程和一个或多个方法，设置训练步数、终端输出间隔和随机种子，页面会显示
所选方法当前开放的全部超参数，并生成可直接保存为
``examples/my_openpinn_run.py`` 的完整 Python 代码。没有专用超参数的方法会明确
标注，不需要填写空参数。

完整代码区独占整行，高度随窗口调整。点击“放大查看”可在大窗口中阅读，
按 Esc 或“关闭放大”返回；代码保留缩进、不自动换行，长行可横向滚动。
可以复制代码，也可以点击“下载 .py”，将下载文件放入项目 ``examples/`` 目录后运行。
参数校验未通过时，复制和下载按钮均不可用。
下载文件按问题名命名：例如内置 Poisson 下载为 ``poisson.py``。
若想使用上面的 ``my_openpinn_run.py`` 命令，必须先把保存的脚本重命名为该名称。
重复下载可能带上 ``(1)``，命令必须与磁盘上的文件名一致。
项目自带 ``examples/poisson.py``，不要覆盖已有示例或自己的旧脚本；
首次跟做可把下载文件另存为 ``first_poisson_run.py``，运行
``python examples/first_poisson_run.py``；Windows 未激活环境时使用
``.\.venv\Scripts\python.exe examples\first_poisson_run.py``。

“终端输出间隔”控制 ``step=... total=...`` 每隔多少个外层训练步打印一次；它与
自适应采样方法中的“重采样间隔”是两件不同的事。

双隧道的数值评估网格不是通用训练参数，因此不在这里显示。新运行默认以
``61 x 61`` 网格保存原始孔压场，图像层会在此基础上做显示插值；不需要在生成
代码中另行设置。

控制方程下拉框中选择“新控制方程（可视化一维/二维）”后，同页会展开
一个配套窗口。用户可选静态或含时间方程、一维或二维区域，并修改坐标范围；
窗口会实时更新控制方程公式、边界和示例场图例。这个图例是建模预览，**不是**
PINN 训练结果。

需要超出固定方程项的表达能力时，选择“方程编辑模式 → 公式与物理参数（推荐）”。
可以编辑单场公式、从常见物理参数库添加参数、定义自有参数、填写数值与单位，
并导入/导出本地扩展库和方程快照。生成代码内嵌参数与表达式树，调用
``op.make_physics_residual``，不是只把公式写进注释。
支持单场孔压扩散、稳态 Darcy 水头和热扩散等示例；示例值不是材料推荐值。
具体语法、单位、边界含义及新增参数的协作流程见 :doc:`physics_library`。
原来的“自由组合”改名为“按项组合（兼容旧版）”，已有用法保持可用。

二维区域还可以从“二维几何”选择“导入多边形文件（识别图片）”。配置器支持 ``CSV``、
``JSON``、``GeoJSON Polygon``、``PNG`` 和 ``JPG``。坐标文件会检查自相交、孔洞位置和孔洞重叠，自动显示
凹多边形或带孔区域，并把坐标直接嵌入复制出的 Python 代码，因此运行时不依赖原始
几何文件。CSV 可写 ``ring,x,y`` 三列（``ring`` 为 ``outer``、``hole_1`` 等）；
JSON 可写 ``{"outer": [[x,y], ...], "holes": [...]}``。当前暂不支持
``MultiPolygon``。导入多边形后，外轮廓与每个孔洞都会按顶点序号生成
``1→2``、``2→3`` 直到“最后一点→1”的独立边界行，每条边可单独选择
Dirichlet、Neumann 或 Robin 并设置参数。
为防止异常文件占满浏览器，单文件上限为 5 MB，每个边界环上限为
5,000 个顶点。

如果几何来自 COMSOL 或 CAD，统一选择“导入 DXF 图纸（COMSOL/CAD）”。
这个选项使用二维 ASCII ``.dxf`` 读取器：
可读取闭合 LWPOLYLINE、传统 POLYLINE、圆与完整椭圆，还可把无缺口、无分叉的
``LINE``、``ARC``、椭圆弧、开放多段线和带完整控制点/节点的 ``SPLINE``
拼成闭环，并把轮廓变为可预览、
可编辑、可逐边设置边界的几何代码。一般圆弧与椭圆在
DXF 导入路径中会离散为短边；若需整个计算域是严格解析圆/椭圆，应直接选择上方的
“圆形”或“椭圆”几何。若导入的孔洞轮廓符合圆形，页面会把它识别为
一个圆孔：按整圈设置一组边界条件，并可修改圆心与半径；生成代码
也会保留这些参数。

**解析圆孔路径：** 外轮廓为四顶点轴对齐矩形且所有孔洞均已识别为圆时，
生成 ``op.RectangleWithCircularHoles``，直接按圆心、半径进行域内判定和圆周采样。
外框保持原来的边号，每个孔仍是一组条件；孔壁外法向指向孔内。
新导入路径启用 ``stratified_boundary=True``：每条外边及每个孔至少一个边界点，
剩余点按周长分配，采样总数不足时明确报错。旧模型默认采样策略不变。

**近似路径：** 倾斜矩形、一般多边形、含非圆孔等情况仍使用 ``op.Polygon``。
页面与生成代码显示分段数；已识别但仍离散的圆孔显示等角重采样最大弦高
``r*(1-cos(pi/N))``，单位与模型坐标一致，不包含图像识别或圆拟合误差。
一般曲线相对原始 CAD 的几何误差尚未估计；暂未提供通用几何布尔运算。

COMSOL 导出时，在 Geometry → Export 选择 DXF，
将 Curve representation 设为 Approximate with polygons。CAD 中请先把要计算
的区域整理成闭合二维边界再导出 ASCII DXF。页面显示 ``$INSUNITS``，并提供
“图纸单位→模型单位”换算系数；例如毫米转米填 ``0.001``。单文件上限 5 MB；不支持直接
读取原生 ``.mph``/``.mphtxt``/``.dwg`` 文件、无法闭合的开放曲线、只有拟合点
而没有完整控制数据的 SPLINE、块引用、
三维几何或多个互不相连的区域。导入后务必核对实际长度单位和坐标范围。
可用 ``examples/geometries/comsol_2d_export_example.dxf`` 试导入
（矩形区域与一个八边形孔洞），或用
``examples/geometries/cad_l_shape_example.dxf`` 试导入
（L 形闭合区域）。它们是按对应 DXF 结构制作的测试样本，不是软件原生工程文件。

页面顶部新增“训练后对比独立参考场”。可选择带列名的 CSV/制表符表格，
或 COMSOL Spreadsheet 风格的 ``%`` 注释加空格分隔数值表；后者用
``#1``、``#2``、``#3`` 等从 1 开始的列序号选坐标和场值。COMSOL 的
`Spreadsheet 格式说明 <https://doc.comsol.com/6.4/doc/com.comsol.help.comsol/comsol_api_fileformats.53.04.html>`_
也采用逐点坐标与数值表。填写
运行时路径、按模型输入顺序排列的坐标列、场值列，以及坐标、参考值和预测值各自的
单位换算系数。双隧道当前默认模型使用 ``X=x/40``、``Y=y/40``、
``tau=t/40``、``U=p/20``，若导出的是米、年和 kPa，页面会预填坐标
``0.025,0.025,0.025`` 和预测值 ``20``；修改了模型物理参数或导出单位时必须同步调整。
若文件只导出某一个时间切片而没有时间列，可填写该切片的时间值；网页会把它作为
模型输入的最后一维，并应用时间换算系数。浏览器不能自动把本地文件复制进项目，
必须把参考表放到填写的路径，再运行生成代码。
若一次导出把多个时间分别放在多个场值列，当前应逐个时间切片评估，
或先整理成长表的 ``x,y,t,value`` 四列；不会猜测列名中的时间参数。
代码调用 ``op.evaluate_reference_csv``，在参考文件的原始坐标/时间点上预测，
生成 ``reference_metrics.json``、``reference_predictions.csv`` 和
``reference_comparison.svg``；L2、RMSE、MAE、R² 使用所有有效行，动态问题的图
只展示最后一个时间切片。文件中的重复同值坐标会去重，冲突值、非数值和已知
计算域以外的坐标会报错；不会偷偷插值或把参考数据用于训练。
指标目前按去重后的每个采样点等权计算；若 COMSOL 网格局部特别密集，
这些指标不是面积加权的全域误差，应另外导出均匀评估网格再作比较。
可用 ``examples/references/poisson_reference.csv`` 做一维 Poisson 短跑测试。
``examples/references/comsol_spreadsheet_example.txt`` 是按 Spreadsheet 结构制作的
无列名测试样本，不是真实 COMSOL 工程导出。

纯圆、椭圆和圆角矩形不再用大量短直线近似圆弧。在“二维几何”中直接选择
“圆形”、“椭圆”或“圆角矩形”：椭圆使用圆心、半轴 ``a/b`` 和逆时针旋转角，
``a=b`` 时精确退化为圆形；圆形使用圆心与半径，圆角矩形使用外框与圆角半径
``r``。``r=0`` 时是普通矩形；正方形且 ``r=边长/2`` 时是纯圆。预览、采样、
外法线和生成代码均保留解析曲线，修改尺寸不会使圆弧变成折线。

PNG/JPG 图片需要是“实心封闭色块 + 对比明显的背景”。页面默认比较背景颜色与
主要填充色的 RGB 色差，灰色和彩色区域即使亮度接近背景也有机会被识别；透明背景
图片还可按透明度提取轮廓。例如白底、灰色矩形、黑色描线及两个白色圆孔，灰色主体
和两个孔洞会一起被识别。仍可切换手动亮度阈值与深色/浅色前景，并修改 ``x/y``
物理范围。处理只在本地浏览器完成：默认使用 1024 像素最长边；可选 384、768、
1536 或最大 2048 像素，并调整 0.25--5 像素的关键拐角简化强度。更高分辨率会
增加处理时间，也无法恢复原图本来没有的细节；自动分割不是照片语义分割，导入后
务必核对预览图的孔洞数量和边界位置。
导入图片时默认分析轮廓转角。若存在连续的小角度转向（圆弧或其他平滑段），页面会
自动生成 ``op.ClosedSpline`` 闭合三次样条；控制点可以拖动，“曲线张力”可以继续
调整弯曲程度，预览、外法线和生成代码同步更新。若轮廓主要由直线和尖锐拐角组成，
则继续生成 ``op.Polygon``，不会把五角星等尖角图形错误抹圆。用户也可以强制选择
样条、纯圆、圆角矩形或多边形。带孔图形目前仍使用多边形轮廓。
默认 2 像素用于清除栅格阶梯造成的伪顶点；标准五角星会保留 10 个必要控制点（5 个外尖角和 5 个内凹角），
而不是把整条像素边都变成控制点。更高分辨率和 1--1.5 像素的简化值能保留轻微不对称；
0.25--0.5 像素可能生成上百个控制点，只建议在需要保留像素级细节时使用。页面保留最大连通色块，
其内封闭背景识别为孔洞。
它不是通用照片语义分割器；细线草图、阴影、渐变或多个分离实体应先整理成高对比填充图。
可直接试用 ``examples/geometries/triangle_silhouette.png``。

识别或导入后，“轮廓编辑器”允许整体旋转、平移、X/Y 独立缩放；可在预览图拖动顶点，
或在表格精确编辑每个顶点的坐标、下一边长和内角，也可增加/删除顶点。预览图中的顶点按表格顺序标为
``1, 2, 3, ...``，每条边显示 ``i→j`` 及当前物理长度；拖动时两者都会实时更新。指针坐标使用页面缩放后的
CSS 像素和 SVG ``viewBox`` 显式换算，因此放大或缩小页面不会使拖动点偏移。每次修改都会
重新检查自相交、孔洞越界等几何错误；生成的 Python 代码使用编辑后的最终坐标。

生成的同一份 Python 代码会同时包含区域、PDE 残差、边界/初值条件、问题名称和
下方选中的改进方法。“常用模板”可选 Poisson、Helmholtz、非线性
Poisson、热方程、三次反应--扩散、Allen--Cahn、对流--扩散与一维
Burgers，并只显示该模板相关的系数。

“按项组合（兼容旧版）”则把方程写成多行“带符号系数 × 方程项”：可组合
``u``、``u²``、``u³``、一/二阶空间导数、时间导数和常用源项。网页会按
维度和静态/动态类型拒绝不合法项，再自动生成所需的自动微分代码。复制到
VS Code 后，可继续修改标有①②③④的代码区域。更多自定义细节见
:doc:`custom_equation`。

.. warning::

   当前统一入口的可视化组合器面向单变量 PDE。矩形支持逐侧 Dirichlet、Neumann
   和 Robin 边界；导入多边形的外轮廓及孔洞也支持逐边独立条件；圆形、椭圆、圆角矩形与闭合样条
   当前对整条连续曲线设置一组条件。周期边界、初始速度
   条件、多区域材料、MultiPolygon 和多变量耦合尚未实现；网页不会把这些功能
   冒充为可运行选项。

.. note::

   生成器只允许当前框架已经验证的组合。同一方法家族只能选择一个具体变体；两个
   方法如果同时控制采样器、网络结构等同一位置，页面会提示冲突。迁移学习还需要把
   示例检查点路径改为真实的 ``checkpoint.pt`` 文件。
