文档范围
--------

当前网站提供安装说明、教程、配置生成器、十类方法及其二级变体、三随机种子复现、API 和质量验证页面。
训练任务通过 Python API 或命令行启动，网页用于查询配置、命令、表格和图。

使用建议
--------

* 在自己的 Python/Conda/CUDA 环境运行 README 中的检查命令；
* 先运行短案例确认环境，再开始正式训练；
* 阅读方法页中的适用范围和负结果，不把单个实验结果推广到所有问题。
