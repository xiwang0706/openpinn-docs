可视化方程设计器（预览版）
============================

这个页面让初学者先用积木表达控制方程，再生成 OpenPINN Python 代码。当前版本支持
一维/二维、静态/含时间、单输出标量方程、统一 Dirichlet 边界和初值模板。

.. important::

   公式预览和结构检查不等于数学证明。生成后应先运行默认 5 步短例子，确认求导、
   维度和保存链路正常；复杂耦合方程、分段材料、圆孔边界和 Neumann 条件仍应使用
   :doc:`custom_equation` 中的 Python 方式定义。

.. openpinn-visual-problem-designer::

试跑的新模型
------------

页面中的“加载新模型：非线性反应–扩散”会自动放入下面这组一维含时间问题：

.. math::

   u_t - 0.1u_{xx} + u^3 = 0,
   \qquad x\in[-1,1],\ t\in[0,1].

边界取 :math:`u(-1,t)=u(1,t)=0`，初值取
:math:`u(x,0)=\sin(\pi x)`。它只是用于检验“新方程 → 生成代码 → 短跑 →
保存结果”的完整链路，不代表已经完成正式收敛验证或方法优越性比较。

怎样操作
--------

#. 选择静态/动态以及一维/二维，填写区域和网络参数。
#. 从左侧工具箱拖出导数、坐标、常数和运算积木，接到“PDE 残差”积木中。
#. 查看右侧数学公式、区域边界和检查提示。
#. 点击“复制代码”或“下载 .py”，保存到项目 ``examples/`` 目录后运行。
#. 短跑通过后，再到 :doc:`method_configurator` 选择改进方法和专用超参数。
