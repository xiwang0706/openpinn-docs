三随机种子复现
================

目的
----

十种方法的单次运行只能说明代码链路可用，不能说明结果稳定。本页使用
``20260827``、``20260828`` 和 ``20260829`` 三个随机种子，逐一重复普通 PINN
与改进方法的配对比较。三次复跑不调参，也不改变训练步数、网络、采样点数或优化器。

运行
----

在项目根目录执行：

.. code-block:: bash

   PYTHONPATH=src python -m examples.reproduce_methods \
     --output-dir runs/reproducibility_three_seed_<timestamp>

如需核查单个方法，可使用 ``--methods fourier``。方法始终按文档中的顺序串行执行，
不会让多个训练任务争用 CPU。

统计口径
--------

* 每个种子内部使用同一个种子比较普通组与方法组；
* 对每个原始指标保存三次的均值、样本标准差、最小值和最大值；
* Poisson 和 Burgers 均以相对 L2 误差作为方法内的主要指标；
* Burgers 相对 L2 来自独立 Cole--Hopf 参考解，只用于评估，不进入训练；
* ``method / baseline < 1`` 表示该方法在对应种子下的主要误差更小；
* 训练时间同样按配对比值保存，但只用于成本记录，不作为精度结论。

输出
----

根目录保存 ``protocol.json``、``summary.json``、``run_status.csv``、``all_variants.csv``、
``aggregate_metrics.csv``、``paired_primary_metrics.csv``、``paired_summary.csv``、汇总 SVG 和失败说明。
每个方法的每个种子目录仍保留配置、历史、误差、时间、预测、检查点、方法对比图和限制说明。

不能只看主要指标。Modified MLP 的相对 L2 下降但 PDE 残差上升；硬边界把边界误差精确压到零但内部 PDE 残差上升；自适应采样的平均 L2 略低，但只有 1/3 种子改善；时间窗在 3/3 种子上的相对 L2 都更差；区域分解改善解和界面通量，但 PDE 残差及成本增加。

迁移学习的时间比只包含目标阶段；源模型预训练平均还需 ``2.493 ± 0.033 s``。
末层部分迁移的平均相对 L2 为 ``0.50374 ± 0.01158``，高于从头训练；虽然目标阶段时间为 ``1.958 ± 0.041 s``，但不宣称它更优。

解释边界
--------

三种子复跑是最低限度的稳定性检查，不等于论文级统计证明，也不能把不同方程的数字放在一起排名。
Adam 与 L-BFGS 的外层步数不是等价计算量；迁移学习的预训练成本必须单独保留；区域分解和 Fourier 特征的参数量与普通网络不同。
