OpenPINN 文档
=============

OpenPINN 是一个可安装、可扩展的 PyTorch PINN 工具箱。用户先定义或选择控制方程，
再用一个方法简称训练；网络组装、求导、评价、计时、画图和保存由统一入口完成。

.. code-block:: python

   import openpinn as op

   result = op.solve(
       "poisson", method="fourier", variant="random_fourier", steps=5000
   )
   print(result.metrics)

把 ``fourier`` 改为 ``adaptive_sampling``、``modified_mlp`` 等名称即可选择其他
方法，不需要复制训练循环。对于新方程，只需写一个返回 ``PDEProblem`` 的小文件，
仍然使用相同的 ``solve`` 入口。

.. note::

   5--20 步短训练只检查代码和输出是否正常，不是精度结论。正式比较应固定问题、
   网络、训练点、步数和随机种子，每次只改变一个方法组件。
